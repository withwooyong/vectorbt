# 키움 조건검색 기반 전략 연구

이 작업은 홈서버의 KRX 일봉으로 여러 매매 전략군을 비교하되, 키움 영웅문4 조건검색에서 표현할 수 있는 조건을 사용하기 위한 사전 조사다. **요청된 네 가지 조사·설계 산출물을 작성했고, 현재 데이터는 진단·구현 준비용으로만 인수한다.** 2015년부터의 본 검증은 백필과 가격 조정·과거 종목 이력 확인이 필요하다. 백필은 다른 프로젝트에서 담당하며 이번 작업에서는 전략 코드나 백테스트 성과를 생성하지 않았다.

## 진행 순서와 결과물

사용자는 2026-09-10에 아래 네 작업을 모두 승인했다. 순서는 **1 → 2·4 → 3**이다. 먼저 조건의 표현 범위를 정하고, 데이터 점검 결과를 백필 인수 기준에 반영한 뒤 실험 명세를 작성한다.

| 순서 | 작업과 목적 | 결과물 | 상태 |
| --- | --- | --- | --- |
| 1 | 키움 항목과 과거 계산 정의 연결 | [조건 대응표](condition-map.md) | 조사 완료, HTS 결과 일치는 후속 검증 |
| 2 | 홈서버의 시장 구분·가격·기간·이력 점검 | [데이터 점검](data-audit.md), `evidence/` | 읽기 전용 실측 완료 |
| 4 | 다른 프로젝트의 백필 결과를 인수할 기준 설정 | [백필 인수 기준](backfill-contract.md), `sql/` | 기준·재실행 SQL 작성 및 현 DB 실행 완료 |
| 3 | 여러 전략군을 같은 조건으로 비교할 실험 설계 | [실험 명세](experiment-spec.md) | 3개 전략군·6개 후보의 연구 명세 작성 완료 |

## 현재 판단과 후속 작업

- 2026-09-10 실측 KRX 일봉은 4,481,979행·4,505종목이다. 1,804종목이 2023-05-11부터 812행만 보유하여 시작 구간 복원이 필요하다.
- 시장 코드 0에는 ETF 등이 섞여 있다. 현재 시장 분류만으로 과거 코스피 보통주를 재현할 수 없다.
- OHLC 관계·중복·음수 거래량 검사는 통과했고, API와 DB의 삼성전자 7일 값이 일치했다. 이는 가격 조정과 생존편향 해결까지 뜻하지 않는다.
- 다른 프로젝트에는 백필 인수 기준을 전달할 수 있다. 여기서는 가격 의미 확인과 HTS 단일 조건 대조 후 구현 단계로 넘어간다.
- 연구 설계안의 보유기간·비용·비중은 명시적 기본값이며 수익성에 맞춰 선택한 값이 아니다. 사용자의 허용 낙폭은 미정이다.

조사에는 공식 자료 확인용 저비용 에이전트와 백필 계약 작성·검토용 에이전트를 사용했다. 본 에이전트가 서버 읽기 전용 실측과 문서 통합·검산을 담당했다. 근거의 전체 데이터 덤프 대신 집계와 7일 API 대조 표본을 저장했다.

## 읽는 순서

먼저 이 문서에서 전체 진행 상태를 확인한다. 조건 대응표는 무엇을 실험할 수 있는지, 데이터 점검은 현재 무엇을 믿을 수 있는지 설명한다. 백필 인수 기준은 부족한 데이터를 채우는 담당자에게 전달할 문서이며, 실험 명세는 구현자가 같은 결과를 재현할 수 있도록 매매와 평가 규칙을 정의한다.

## 범위와 판단 원칙

- 사용자의 확정 요구: 여러 전략군 비교, 키움 조건검색으로 설정 가능한 조건, 홈서버 일봉 사용, 2015-01-02부터 별도 백필.
- 연구 제안: KRX 일봉 마감 후 판단, 다음 거래일 주문, 공매도·레버리지 없는 공통 계좌 모형. 실험 숫자는 투자 권고나 최적값이 아니다.
- 원본 DB 변경·백필 실행·수집 POST·조건식 저장·실주문은 이 작업의 산출물이 아니다.
- 문서상 조건 지원, Python 정의 작성, HTS 결과 일치는 각각 별도 상태다. 실제 일치 확인 전에는 완전 호환으로 표시하지 않는다.
- 서버 계정·토큰·환경변수는 수집하지 않는다. 저장하는 증거는 스키마와 집계값 및 공개 API의 최소 표본이다.
- 장기 커버리지, 상장폐지 및 과거 시장 이력, 가격 조정 기준을 통과하기 전에는 전체 코스피의 성과를 주장하지 않는다.
