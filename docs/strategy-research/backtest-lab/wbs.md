# WBS: 전략 일괄 백테스트 프로그램 구현 계획

이 WBS는 **문서 설계 → 데이터 계약 → 계좌·청산 엔진 → 일괄 실행·저장 → 비교·선정**의 순서와 완료 증거를 정한다. 2026-09-13에 연구 핵심 프로그램과 회귀 검사를 추가하고 실제 DB 추출·품질 판정까지 실행했다. 데이터 인수 실패로 실제 수익률 비교·전략 선정은 보류했다. [구현·실행 결과](implementation-and-results-2026-09-13.md)와 검증 기록을 완료 증거로 사용한다. 아래 상태는 전체 인수 기준과 실제 구현의 차이를 남긴다. 사용자는 1억 원·익절/손절 사전 지정·최대 1개월·무인출 재투자 조건의 전략 한 개를 찾으려 한다.

핵심 경로는 W01→W02→W03→W05→W07→W09→W11→W12→W13→W14이다. 데이터 인수에 필요한 외부 이력이 지연되면 합성 자료로 구현·회귀 검사까지 진행할 수 있지만 실제 성과와 선정은 인수 수준에 맞게 제한한다. 담당은 개발 역할이며 실제 인원·완료 날짜를 약속한 일정표가 아니다.

## 4. 구현 전에 고정할 정책과 외부 의존

사용자의 투자금·인출0·1개월·TP/SL은 확정 방향이다. 아래 숫자는 설계 제안이므로 실제 성과를 보기 전에 버전을 고정한다. 수정이 필요해도 기존 실험 기록을 덮어쓰지 않는다.

| 결정/의존 | 현재 제안 또는 상태 | 필요한 시점 |
| --- | --- | --- |
| 1개월의 의미 | 달력 1개월·비거래일 직전 시가. 20/21거래일로 대체하지 않음 | W01 |
| 위험·배분 | 연구 MDD20%, 종목5%, 거래 위험0.5%, 업종25%, 목표투입80% 제안 | W06 및 성과 열람 전 |
| 투자대상 | 당시 KOSPI·KOSDAQ 보통주를 기본 제안, ETF/우선주/스팩 별도 제외 계약 | W02,W03 |
| 역사 자료 | raw/adjusted 관계·기업행사·상폐 정산·정지·달력·업종 이력 필요 | W03 |
| 실제 비용 | 날짜·시장·계좌별 수수료/세금 근거와 슬리피지 추정 필요 | W03, 최종 선정 전 |
| 기간 사용 이력 | 2024~2026 자료가 이미 선택에 쓰였다면 잠금 재지정 | W11, 잠금 열람 전 |

이 항목이 모두 해결될 때까지 설계·합성 테스트를 멈출 필요는 없다. 원본 데이터 인수와 실전 위험 결정이 필요한 작업만 해당 게이트에서 제한한다.

## 5. 범위 밖 후속 WBS

본 프로젝트에서 기술전략을 고른 뒤 증권사 검색식 동일성, AI 뉴스 검토·캐시, 무주문 실시간 관찰, 모의 체결·목표/손절 경합, 제한 실전은 별도 버전으로 수행한다. [후속 자동매매 설계](../paper-live-news-roadmap.md)를 참고하되 이번 연구 배치에 뉴스·실주문을 추가하지 않는다. 기존 원본 프롬프트와 홈서버 가격 DB는 보존한다.
