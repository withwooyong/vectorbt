# 독립 실자료 확보 경로 조사 WBS

목적: vectorbt가 ted-startup의 수집 일정과 분리해 2015-06-15 이후 KRX 보통주 백테스트 데이터를 확보할 수 있는지 검토한다. **정정된 판단:** 이 WBS의 100%는 문서 작성 완료만 뜻한다. 실제 독립 수집 가능성을 입증하지 못해 기존 계획의 실행 가능 판정을 철회했고 [재검증 WBS](independent-data-feasibility-audit-wbs-2026-09-19.md)에서 다시 감사했다. 범위: 공개 자료·현재 저장소 계약 대조와 조건부 수집 설계 문서. 한계: 인증키 발급, 대량 수집, 유료 계약, 운영 DB 변경은 포함하지 않는다.

진행률: **100%** · 완료 **4/4** · 이 문서 작성 작업의 남은 일: 없음 · 실제 수집 가능 여부: **미확정**. 이 진행률은 수집·인수·백테스트의 완료율이 아니다.

## 판단과 검증 기록

- 사용자 요청은 독립 수집 **방법 조사와 문서 작성**이다. 실제 API 호출과 수집은 후속 단계로 둔다.
- 2015-06-15부터 성과를 측정하되 250봉 지표 준비를 위한 이전 가격은 별도 warmup 구간으로 취급할 예정이다.
- 기존 r2 전달본과 vectorbt의 REAL 차단은 비교 기준이며 새 수집 경로의 자동 인수 근거가 아니다.
- 독립 검토에서 KRX 계약 종료 후 사용 제한, 증권사 가격 경로의 독립성 표현, 현재 전략의 시가총액 필수 여부를 수정했다.
- 공식 문서 링크와 로컬 문서 링크를 대조하고 `git diff --check`를 통과했다. 문서만 수정했으므로 코드 테스트는 실행하지 않았다.
