# 독립 데이터 확보 가능성 재검증 WBS

목적: 기존 [독립 수집 계획](independent-krx-data-acquisition-plan-2026-09-19.md)의 주장마다 실제 검증 수준을 확인하고 가능한 작업과 불가능·미확인 작업을 분리한다. 현재 판단: 공개 명세·비인증 응답까지 재검증했지만 전체 데이터의 독립 수집 가능성은 입증되지 않았다. 범위: 공식 출처·공개 명세·로컬 코드와 권한 상태, 문서 정정. 한계: 인증키 없는 응답 내용과 유료 데이터 계약은 직접 확인할 수 없다.

진행률: **100%** · 완료 **4/4** · 이 재검증의 남은 일: 없음 · 실제 수집 가능성의 차단: 인증 표본과 제공 계약 부재, 사건·상폐 정산·비용의 전수 경로 미확정. 이 진행률은 데이터 수집 완료율이 아니다.

## 판단과 검증 기록

- 이전 문서의 `100%`는 조사 문서 작성 범위의 완료였으며, 실제 경로의 수집·인수 가능성을 입증하지 못했다. 사용자 지적을 반영해 이 WBS를 별도로 연다.
- 환경변수 이름 확인에서 KRX·KIS·키움·토스·DART 인증키는 발견되지 않았다. 비밀 파일이나 운영 DB는 열지 않았다.
- KRX 유가 일별 공식 페이지의 `var bld` Base64 공개 명세에서 날짜·OHLCV 필드를 확인했고, 키 없는 공식 표본 URL은 HTTP 401이었다. 가격의 원/조정 의미와 응답 완전성은 미검증이다.
- 키움·KIS·토스는 과거 일봉 API 문서가 있으나 전수 상폐/기업행사/정산의 근거는 확인되지 않았다. DART 사건 API는 공시 일부만 제공한다.
- 독립 검토가 지적한 KRX 원가격 가정, 상태 필드 가정, 영구 ID 가정과 장기 로컬 사용권을 정정했다. 로컬 링크 검사·변경 형식 검사를 수행했다. 문서 작업이라 코드 테스트는 실행하지 않았다.
