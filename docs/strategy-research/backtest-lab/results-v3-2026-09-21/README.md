# 기본 청산과 넓은 청산의 실제 백테스트 결과

**비교 가능한 21쌍에서는 넓은 청산의 평균 손실이 줄었지만, 평균 수익률은 여전히 음수였다.** 2026-09-21 실제 자료로 2,464개 실행을 마쳤으며 2,023개는 성공, 441개는 차단됐다. 아래 비교는 기본·넓은 청산 모두 2020~2023년 검증을 통과한 **21쌍 / 56쌍**에 한정한다. 전체 시장 성과나 전략 선정 결과가 아니며, 현금배당은 제외했다. 저장 장부의 재검증, 상세 보고서·그림 생성과 최종 독립 검토를 모두 마쳤다.

## 먼저 볼 결과

같은 진입 조건끼리 비교한 21쌍에서, 넓은 청산은 16쌍의 평균 연간 수익률을 높였고 5쌍은 낮췄다. 네 해는 해마다 1억 원으로 새로 시작했으므로 연속 4년 복리 수익률이 아니다.

| 같은 21쌍의 비교 | 기본 청산 | 넓은 청산 |
| --- | ---: | ---: |
| 평균 연간 수익률 | −10.79% | −3.89% |
| 가장 나빴던 해의 최대 낙폭 평균 | 19.74% | 19.40% |
| 평균 투자 비중 | 22.54% | 31.42% |

수익률 차이는 **+6.89%포인트**다. 최대 낙폭은 계좌가 고점에서 얼마나 떨어졌는지를 뜻한다. 표에서는 각 조합의 네 해 중 가장 큰 낙폭을 고른 뒤 21개 조합을 평균했다. 손실 감소와 달리, 이 낙폭은 크게 줄지 않았다. 평균 투자 비중은 연도별 일평균 투자 비중을 네 해·21개 조합에 걸쳐 단순 평균했다.

청산별 비교에서도 기본과 넓은 조건 모두 네 해가 성공한 진입 조합만 사용했다. 행마다 비교 가능한 조합이 다르므로 행 간 순위로 읽지 않는다.

| 손절 / 익절: 기본 → 넓은 조건 | 비교 쌍 | 기본 평균 연간 수익률 | 넓은 평균 연간 수익률 |
| --- | ---: | ---: | ---: |
| −3% / +6% → −8% / +16% | 7 | −17.58% | −6.10% |
| −5% / +10% → −10% / +20% | 7 | −12.00% | −4.86% |
| −1.5 ATR / +3 ATR → −3 ATR / +6 ATR | 3 | −2.59% | −0.95% |
| −2 ATR / +4 ATR → −4 ATR / +8 ATR | 4 | −2.93% | −0.53% |

ATR은 최근 14일의 가격 변동폭이다. 넓은 손절은 허용 손실 금액을 유지하기 위해 매수 수량도 줄인다. 따라서 이 비교에는 청산 시점뿐 아니라 매수 수량과 투자 비중의 변화도 함께 반영된다.

예를 들어 −3% / +6%를 −8% / +16%로 넓힌 7쌍에서는, 종료된 거래의 평균 보유기간이 **2.3일 → 11.6일**로 늘고 거래 수는 **28,445건 → 10,196건**으로 줄었다. 이는 네 해·7개 조합의 거래를 모은 수치이며 보유기간은 달력일 기준이다. 잦은 청산이 줄었다는 관찰은 가능하지만, 수익 개선의 원인을 청산 폭 하나로 단정할 수는 없다.

## 441개 실행을 차단한 이유

| 실험 | 성공 | 차단 | 합계 |
| --- | ---: | ---: | ---: |
| 기본 청산 | 1,039 | 193 | 1,232 |
| 넓은 청산 | 984 | 248 | 1,232 |
| 합계 | 2,023 | 441 | 2,464 |

436개 실행은 보유 종목의 거래상태를 확정할 수 없었다. 해당 날짜에는 종가가 있지만 시가·고가·저가·거래량이 0이고 상태가 `UNKNOWN`이었다. 나머지 5개는 보유 중 코스닥에서 코스피로 옮긴 종목의 처리 범위를 벗어났다. 전자는 원천 자료·상태 확인, 후자는 실행 모델 보완이 필요하다. 차단된 실행에는 수익률을 부여하지 않았다.

차단된 실행 중 2개에는 앞선 거래정지 경고도 함께 있어 사유 발생 횟수는 443회다. 이는 서로 다른 차단 실행 441개와 구분한다. 결과를 본 뒤 조건을 완화해 성공으로 바꾸지는 않았다.

## 이번 비교가 답하려는 질문

수정가격으로 만든 신호와 원가격 체결을 연결했을 때, 기본 청산 4개와 넓은 청산 4개가 각기 56개 전략 안에서 어떤 차이를 보이는지 기록한다. 기본과 넓은 청산은 별도 실험이며, 이 결과로 전략을 고르거나 실제 매매를 승인하지 않는다.

| 구분 | 기본 실험 | 넓은 청산 실험 |
| --- | --- | --- |
| 청산 조건 | −3% / +6%, −5% / +10%, −1.5 ATR / +3 ATR, −2 ATR / +4 ATR | −8% / +16%, −10% / +20%, −3 ATR / +6 ATR, −4 ATR / +8 ATR |
| 진입 조건 | 기존 12개 + 상대거래량 돌파 2개 | 동일 |
| 비교 수 | 56개 | 56개 |

ATR(최근 14일 가격 변동폭)과 청산 기준은 신호가 나온 날의 종가를 기준으로 한다. 모든 청산 조건은 명목상 손실 1에 이익 2의 비율이다.

## 고정한 실행 방법

- 신호는 수정 OHLC와 원거래량으로 만들고, 주문·현금·평가는 원가격을 쓴다. 현금배당은 이 가격 수익률에 포함하지 않는다.
- 초기 자금은 각 실행마다 1억 원이며, 최대 20종목을 보유한다. 같은 업종 투자금 제한은 적용하지 않는다.
- 개발 구간은 2015-06-15~2019-12-31이다. 검증은 2020~2023을 해마다 각각 1억 원으로 새로 시작하는 독립 실행이다. 따라서 네 해 평균은 연속 4년 계좌의 수익률이 아니다.
- 실제 날짜별 비용은 매수·매도 각각 0.015% 수수료(10원 미만 절사라는 사용자 가정)와 해당 날짜의 매도세 규칙을 적용한다. 고정 bps 비용·지연 조건은 별도 민감도 점검이며 날짜별 비용 결과와 섞어 순위를 만들지 않는다.

## 입력 범위와 중요한 한계

실행 입력은 KOSPI·KOSDAQ 보통주 중 원가격·수정가격·상태·기업행사 조건을 확인한 **1,076 / 2,787종목**이다. 1,711종목은 불완전 가격쌍, 미해결 행사·조정계수, 상태 또는 인수 이슈 때문에 제외됐다. 이 사후 제외는 생존·제외 편향을 만들 수 있으므로 전체 시장 성과로 일반화할 수 없다.

무거래, 원가격 결측·비정상, 정지·부분거래에는 주문을 체결하지 않는다. 보유 중 미확정 사건의 영향은 별도로 기록하며, 자료가 있다는 사실만으로 실거래 적합성이 생기지 않는다.
