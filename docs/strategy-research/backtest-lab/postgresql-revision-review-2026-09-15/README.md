# 새 revision 판단: 정식 백테스트는 아직 불가하다

2026-09-15 23:37 KST에 ted-startup 최신 문서·배포 코드와 home PostgreSQL을 읽기 전용으로 확인했다. **새 revision은 0원 행 감시를 추가했으며 과거 가격 결손을 정정하지 않았다. 현재 vectorbt 연구의 정식 실자료 백테스트는 `BLOCKED`다.** 판단 범위는 기존 2015~2023 연구 입력과 현재 연구 실행 경로다. ted-startup 자체 백테스트 결과의 적합성을 별도로 승인하는 검토는 아니며, 2024년 이후 가격은 조회하지 않았다.

## 확인한 결과와 의미

배포 성공, 가격 데이터 인수, 연구 실행 지원은 각각 다른 조건이다. 이번 배포는 운영 감시를 개선했지만 나머지 두 조건을 충족하지 않는다.

| 조건 | 현재 확인 결과 | 백테스트 판단 |
| --- | --- | --- |
| 새 배포 | signal backend/frontend `734dbcc`, 컨테이너 6개 healthy. kiwoom 감시 파일 2개는 로컬 최신 코드와 줄바꿈 정규화 후 SHA-256 일치 | 배포된 감시 코드 확인 |
| 과거 거래 가격 | 수정주가 `TRADED` 중 비양수 가격 699행: `102950` 695행 + KRX 4행 | 이전 차단 유지 |
| 변경 키 | 이전 검사와 수정 699 + 원가격 13, 전체 712 영향 행의 키·가격·거래량·상태가 동일 | 해당 결손의 정정·분류 변경 없음 |
| 실제 데이터 실행 | `runner.run_delivery`는 REAL 입력을 `REAL_EXECUTION_NOT_ADMITTED`로 거절. 인수 검사도 REAL을 실행 허용으로 승격하지 않음 | 데이터 보완 이후에도 실제 어댑터·인수·실행 검증 필요 |

수정주가 전체는 6,109,214행, 그중 `TRADED`는 5,897,591행이다. `102950` 결손은 2015-01-20~2019-11-28의 종가 0·거래량 양수 695행이다. KRX 결손 4행은 `015540`, `016385`, `053870`, `141070`의 일부 OHL 0이다. 비거래·정지 행의 0 표기와 분리했으며 이 699행을 자동 삭제·전일 채움·종목 전체 제외하지 않았다.

ted-startup 최신 HANDOFF는 PR #55의 `a6bb9cc`를 감시 cron 구현으로 설명하고, 운영 조회에서도 설명되지 않는 699행이 남았다고 명시한다. 최근 창 신규 0건과 기준선 699 이하는 알림을 울리지 않는 조건이며 **가격 품질 통과 조건이 아니다.** `zero_price_audit.py`도 삭제·보간·정정 없이 결손을 드러내는 기능이라고 설명한다. `102950`의 원가격 행이 없어 역산할 수 없다는 문서의 판단은 별도 원문 납품으로 보완해야 한다.

## 다음 작업 권장안

**권장 순서:** ted-startup에서 699행의 원문·단위·조정 정의를 확보해 근거 있는 정정 또는 공식 상태에 따른 분류를 새 데이터 revision에 연결한다. 원문을 확보할 수 없는 범위는 미확정으로 남긴다. 이어 vectorbt에서 실제 형식의 읽기 전용 어댑터와 원가격·기업행사·역사 종목·공식 거래일·현실 비용 인수 및 실행 경로를 검증한다. 코드 배포 revision과 dataset_id/revision은 구분한다.

이 조건이 충족된 뒤 2015~2023 후보 비교를 진행한다. 기존 사용자의 미검증 자료 수익률 우회 금지와 2024년 이후 가격 잠금은 유지한다. 이번 요청은 가능 여부 판단이므로 원천 수집·DB 정정·백테스트·푸시는 실행하지 않았다.
