# 전략 후보 안내와 실자료 실행 계획 WBS

목적: `krx_lab`의 48개 후보와 합성 검증 범위를 설명하고, ted-startup의 데이터 전달 이후 vectorbt에서 실자료 백테스트를 여는 순서를 문서화한다. 현재 판단: [안내 문서](strategy-catalog-and-real-data-plan-2026-09-18.md)는 검증을 마쳤으며 실자료 실행은 별도 구현·검증 전까지 차단이다. 범위: 현재 코드와 계약의 읽기 전용 확인 및 안내 문서. 한계: 이 WBS는 실자료 실행 구현이나 성과 검증을 완료로 표시하지 않는다.

진행률: **100%** · 완료 **4/4** · 남은 문서 작업: 없음 · 실자료 실행 차단: 별도 로드맵 1~4단계 미완료. 아래 진행률은 이 문서 작업만의 가중 검증 완료율이다.

## 판단과 검증 기록

- 용어: 설명에는 `데이터 전달`을 쓰고, 코드 식별자 `delivery`는 유지한다.
- 파일 소유: 두 감사 담당은 읽기 전용이며 메인이 이 WBS와 안내 문서를 작성·검증한다.
- 독립 검토: 지연을 거래일로 명확히 하고 청산 계획의 호가·기업행사 조정을 반영했다. 48/816/849와 과거 합성 64+33 기록은 코드·문서와 대조했다.
- 검증: 본문 상대 링크 29개 모두 존재, 새 문서 후행 공백과 요청한 용어 없음. `git diff --check` 통과. 문서 변경이므로 pytest·실자료 실행은 하지 않았다.
- 실자료 실행 개발은 이 문서 작업의 완료율 분모에 넣지 않는다. 별도 구현 작업으로 관리한다.
