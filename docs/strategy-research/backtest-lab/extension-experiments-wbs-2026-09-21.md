## 판단과 검증 기록

- 최종 2,598개 저장 장부 전수검증 및 직전 1개월 560개 상태·지표·체결횟수 일치 PASS. 성공 1,842개, 차단 756개(UNKNOWN_HELD_MARK 750, HELD_MARKET_CHANGED 6). [검증 기록](results-extension-2026-09-21/verification.json)에 배치 summary 해시를 보존했다.
- 보고서 생성 시 통계·성과의 중복 필드 오류를 수정했다. 장부 검증 완료 기록과 동일한 summary 해시임을 확인한 뒤 `--render-verified`로 표만 재생성했다. 중복 수치 불일치 회귀를 포함한 보고 테스트 **12 passed, 3.73초** 및 핵심 정적 검사·diff 검사 통과.
- 독립 검토에서 상세 2,598행의 전체 성과·통계·차단사유, 연간 433행의 성공연도·수익률·낙폭·횟수 합계를 원본으로 재계산해 일치했다. 차트 연평균 패널을 핵심표와 같은 고정4년×3기간 표본으로 수정하고 실제 PNG 두 장의 잘림·겹침을 확인했다.
- 핵심 판단은 [결과 해석](results-extension-2026-09-21/interpretation.md)에 기록했다. 신규 최고 관찰 후보는 사후 선택이며 개발기간 차단·기말미청산 평가·자료 한계를 함께 표시했다. 2024년 이후 자료는 열지 않았고 커밋·푸시는 수행하지 않았다.

- 사용자 요청으로 세 신규 가설과 기존 전략의 3·6개월 최대 보유기간 실험을 실행한다. 신규 구현과 로컬 실행은 승인되었으며 푸시는 요청 범위가 아니다.
- 기존 기본 56개·넓은 청산 56개를 모두 보유기간 비교에 포함한다. 날짜별 실제 비용·지연 1거래일을 주 비교로 사용한다. 비용 스트레스 전체 격자 재실행은 이번 주 질문과 분리한다.
- 기존과 같은 독립 연도 비교를 보존하되 연말 보유 절단의 영향을 명시한다. 이미 본 2020~2023년은 새로운 독립 검증으로 부르지 않는다.
- 엔진과 신호 파일 소유권을 분리해 병렬 구현한다. 기존 준비 입력 생성 파일은 변경하지 않아 봉인된 입력을 재사용한다.
- 시장 지수가 없으면 대용 지수를 만들지 않고 해당 가설을 차단으로 기록한다. 데이터 수집·정정은 ted-startup 소관이다.
- 기본 1개월 결과를 변경된 엔진에서 재계산해 이전 저장 결과와 대응 검증한다. 기존 결과·입력은 덮어쓰지 않는다.
- 실행 계획은 기본 1,008개 + 넓은 청산 1,008개 + 신규 582개 = 2,598개다. 각 조합은 개발기간, 2020·2021·2022·2023 독립 연도, 2020~2023 연속 계좌의 여섯 창을 사용한다. 신규 돌파 가설은 20·60일 돌파 × 기존 8개 최초 손절 기준 × 1·3·6개월이며, 모멘텀은 월간 교체이므로 강제 개월 만기를 두지 않는다.
- 모멘텀은 월말 t에서 C(t−1개월)/C(t−12개월)−1로 순위를 매긴다. 통합 상위20개를 다음 시가에 거래하고 새 종목당 최대4%를 배분한다. 기존 보유 수량은 유지하여 비중이 변동하며, 월별 완전 동일가중 재조정은 아니다. 공식 지수200일 필터는 당일 종가로 판정하고 다음날 주문에만 사용한다.
- 추세 청산은 수정종가가 당일을 제외한 직전20개 공식 거래일의 수정저가 최저치를 하회하면 다음 시가에 청산한다. 최초 손절과 기존 수량 규칙은 유지하고 고정 익절만 해제한다. 청산 입력이 불완전한 보유 실행은 차단한다.
