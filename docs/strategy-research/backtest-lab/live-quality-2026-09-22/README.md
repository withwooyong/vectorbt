# 운영 DB 재조회: 백테스트 데이터 품질과 매수 조건

2026-09-22 운영 DB를 실제로 읽기 전용 조회했다. **최근 일봉 수집은 확인되지만, 과거 전체 시장을 편향 없이 백테스트할 품질은 아직 확보되지 않았다.** 기존 1,076종목의 제한된 연구와 전체 시장·실거래 적용을 구분해야 한다. 이전 답변의 로컬 점검만으로는 현재 운영 상태를 설명하기 부족했다.

조회는 13:55~14:01 KST에 수행했다. 2014~2023년 가격 품질과 최신 수집 날짜·건수·시각을 확인했다. 2024년 이후 가격값·수익률은 조회하지 않았다. 최신 일봉 건수에는 보통주 외 상품이 포함될 수 있으므로 과거 보통주 종목 수와 직접 비교하지 않는다.

## 1. 최신 수집은 확인됐지만 전체 완료 판정과는 다르다

최근 구간의 마지막 저장 거래일은 2026-09-21이다. 아래는 그 날짜의 저장 현황이며, 오늘(9월 22일) 장중 일봉이 없다는 이유로 누락이라고 판정하지 않는다.

| 시장 | 원가격 종목 수 | 수정가격 종목 수 | 원가격 마지막 수집 | 수정가격 마지막 수집 |
| --- | ---: | ---: | --- | --- |
| KRX | 4,406 | 4,406 | 9/22 09:01:32 KST | 9/22 06:20:55 KST |
| NXT | 603 | 603 | 9/22 08:58:49 KST | 9/22 06:18:47 KST |

새 원천 계보인 source_request/source_payload에서는 9/19 이후 키움 차트 요청 9,974건이 HTTP 200으로 기록됐고 마지막 요청·응답 저장은 9/22 11:56:22 KST다. 이 그룹에서 payload 연결이 없는 요청은 0건이다. HTTP 200은 API 본문 성공·대상 전체 수집 완료·최신 일봉 확정의 증명이 아니다. 이 요청들은 특정 거래일 일봉 수집과 동일한 모집단으로 단정할 수 없다.

구형 raw_response 저장소에는 9/14 이후 기록이 없었다. 그러나 새 원천 계보와 일봉 fetched_at에는 최신 기록이 있으므로 구형 테이블만 보고 수집 중단으로 판단하면 안 된다. 스케줄러별 전체 작업 성공 여부와 최신 대상 종목군 대비 완전성은 이번에 확정하지 않았다.

## 2. 과거 자료의 현재 품질: 원가격은 날짜가 채워졌지만 수정가격과 사건 처리가 불완전하다

범위는 2014-01-01~2023-12-31의 KOSPI·KOSDAQ 보통주이며 실제 가격 날짜는 2014-01-02~2023-12-28이다. 역사 종목군의 유효기간과 공식 개장일을 결합한 기대 종목·거래일 키를 현재 가격과 대조했다. 따라서 단순 최초·최종 날짜 확인보다 강한 누락 검사지만, 기대 종목군 자체의 역사적 정확성을 새로 증명한 것은 아니다.

| --- | ---: | --- |
| KRX 원가격 | 5,099,694행 / 2,787종목 | 기대 종목·거래일 키 누락 0, 중복 0 |
| 키움 수정가격 | 4,574,759행 / 2,312종목 | 기대 키 524,935개 누락, 중복 0 |

수정가격이 없는 475종목과 524,935개 종목·거래일 키는 다른 단위다. 원가격 누락 0도 정상 체결 가능한 봉이 모두 있다는 뜻은 아니다. 시가·고가·저가 0인 비거래 봉이나 상태 미확정 행이 포함된다.

기존 인수 이슈는 총 2,304건이다. 수정가격 부재 475, 준비봉 부족 306, 미해결 기업행사 160, 설명되지 않은 수정계수 1,061, 과거 다른 원천 가격 오류 301, 업종 이력 제한 1건이다. 과거 오류 기록 301건을 현재 소비 가격에서 다시 발견한 오류 수로 해석하면 안 된다.

## 3. 어제와 비교해 무엇이 달라졌는가

동일한 과거 품질 SQL과 메타데이터 SQL을 다시 실행했으며, 조회 시각을 제외한 모든 결과가 9/21 저장 결과와 같았다. v3는 여전히 SEALED이고 등록된 revision/member 메타데이터도 같다. 새로 등록된 v4는 확인되지 않았다. **현재 확인한 집계에서는 어제의 품질 문제가 해소됐다는 증거가 없다.**

이번에 추가로 공식 달력×역사 종목군에 대한 원가격/수정가격 누락 검사를 수행했고, 최신 일봉 저장 및 원천 요청 시각을 확인했다. **운영 가격 9,674,453행의 실제 내용 해시도 재계산해 봉인 PRICE member와 일치했다.** 해시는 `77505ba4e6829f74d8cdf56d5fbd1877525cdff36b447f01f3972d40881b722f`다. 가격 member의 내용 동일성을 확인한 것이며, 나머지 10개 member 전체와 모든 payload 원문 바이트를 다시 해시한 것은 아니다.

## 4. 기존 백테스트에서 믿을 수 있는 범위

기존 입력은 원래 2,787종목에서 1,711종목을 제외한 1,076종목이다. 이 선택은 전체 기간의 가격·기업행사 완전성을 보고 이뤄져 사후 제외 편향이 있다. 1,076/2,787은 데이터 정확도가 아니다.

로컬 실행 입력에는 187종목의 5,360개 UNKNOWN 종목·거래일이 남아 있다. 최근 확장 실험의 차단 756회는 보유 평가 미확정 750회와 시장 이전 6회다. 동일 문제를 여러 전략이 반복해 만난 횟수이므로 원천 오류 756개를 뜻하지 않는다. 성공 결과도 현금배당 제외, 일봉 체결 가정, 사후 종목 제외라는 한계를 유지한다.

현재 권장 순서는 다음과 같다.

1. 실제 보유 성과를 차단한 날짜별 상태와 시장 이전 사례를 우선 확인한다.
2. 수정가격 누락 및 미해결 수정계수·기업행사를 보완해 제외 종목을 복원한다.
3. 사후에 전체 종목을 제외하는 방식에서 당시 이용 가능 정보에 따른 종목·날짜별 정책으로 전환한다.
4. 배당·장기보유 전략에는 배당 현금흐름과 권리 처리를 추가한다.
5. 범위를 고정한 뒤 새 독립 검증기간을 사용한다. 이미 관찰한 2020~2023년을 새로운 검증기간으로 부르지 않는다.

수집·정정은 ted-startup, 인수·전략·장부 검증은 vectorbt에서 담당한다. 이번 작업은 조회와 보고이며 데이터 수정이나 백테스트 재실행은 하지 않았다.

## 5. 현재까지 실제 사용한 매수 조건 17개

각 행의 변형은 별도 전략이다. 모든 조건을 한 번에 결합한 것이 아니다. 가격 신호는 수정가격 기준이며 SMA는 단순이동평균, EMA는 지수이동평균이다.

| 유형 | 사용 조건 | 개수 |
| --- | --- | ---: |
| 이동평균 교차 | 5일선 또는 10일선이 20일선을 상향 돌파: 전일 아래, 당일 위 | 2 |
| 종가 돌파 | 종가가 직전 20일 또는 60일 종가 최고값 초과 | 2 |
| 돌파+상대거래량 | 위 돌파와 당일 거래량/직전 20일 평균 거래량 ≥1.5, 평균에서 당일 제외 | 2 |
| 상승추세 눌림 | 종가>SMA60, 최근 3거래일 수익률 ≤−3% 또는 ≤−5% | 2 |
| RSI 회복 | 종가>SMA60, RSI14가 전일 30/40 미만에서 당일 해당 값 이상으로 회복 | 2 |
| 볼린저 재진입 | 종가>SMA60, 전일 하단 아래→당일 하단 이상; SMA20−1.5σ 또는 −2σ, 20일 모집단 표준편차 | 2 |
| MACD 교차 | EMA12−EMA26이 EMA9 신호선 상향 교차, 종가>SMA60 또는 SMA120 | 2 |
| 돌파+시장 필터 | 20/60일 종가 돌파, 해당 시장 KOSPI/KOSDAQ 지수>SMA200 | 2 |
| 월간 상대 모멘텀 | 월말 C(t−1개월)/C(t−12개월)−1 순위, 두 시장 통합 상위20 | 1 |

눌림 3·5는 하락률 문턱 −3%·−5%이며 둘 다 3거래일 수익률이다. 돌파는 장중 고가 돌파가 아니다. 최초 14개와 시장 필터 변형에는 전일 거래량 10만 주 이상과 연속 완전 250봉 조건을 적용한다. 월간 모멘텀은 별도 과거가격 완전성·적격성 규칙이다.

신호와 실제 체결은 별도다. 일반 전략은 다음 거래일 시가가 신호일 종가+0.5 ATR과 종가+1% 중 작은 상한 이하여야 한다. 최대20종목·전체 진입비중80%·비용포함 종목당4%·20일 평균 거래량의0.1% 수량 상한을 적용하고 일반 전략은 계획손실0.5%도 제한한다. 모멘텀은 별도 시가 주문과 4% 신규 배분을 사용한다. 시가총액·실제 거래대금·재무·투자자 수급은 이 매수 조건에 포함하지 않았다.

직전20일 저가 이탈은 신규 매수조건이 아니라 기존 돌파 전략의 청산 변경이다. 최대 보유기간 1·3·6개월과 PCT/ATR 손절·익절도 매수 신호와 구분한다.

- [공식 개장일 대비 누락 검사](coverage-r2/results.json). 최초 coverage 시도는 SQL 별칭 오류로 실패했고 coverage-r2에서 수정 후 완료했다. 실패 기록은 보존했다.

- 2024년 이후 가격값·수익률, 현재 API 응답 본문, 계좌별 수수료, 최신 전체 종목 기대집합 대비 수집 완료, 모든 원천 payload 바이트 재검증은 이번 확인 범위가 아니다.
