## 판단과 검증 기록

- ted-startup은 수집·정정·데이터 전달을 맡고, 이 저장소는 검증·전략·백테스트를 맡는다.
- 실자료 실행 차단을 제거하는 작업은 데이터 인수·원가격 장부·현실 비용 검증과 함께 별도 단계에서 진행한다.
- 병렬 작업은 새 파일로 소유 범위를 나누며 메인이 CLI 연결·문서·검증을 맡는다.
- `inspect_real_readiness`는 C1 검사 문제와 C1 밖에 남은 근거 공백을 보고한다. 임의의 새 필수 입력 필드는 요구하지 않으며 결과를 실행 적격으로 승격하지 않는다.
- 독립 검토의 출력 파일 충돌·무효 C1 보고 구조 지적을 수정했다. CLI는 입력 폴더 내부 출력을 거절하고 새 결과 파일을 독점 생성한다.
- 검증: `uv run --python .venv --no-sync pytest tests/research -q` → 376 passed (89.18초). 변경 파일 Ruff 검사 통과. 오프라인 표본과 CLI 관련 신규 검사 6개를 포함한다. 실제 DB 데이터·수익률은 실행하지 않았다.
