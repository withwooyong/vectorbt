## 판단과 검증 기록

- 이번 입력은 기존 C1 납품·원가격 신호·6개 합성 평가 구간·합성 FROZEN 증거다. 날짜별 비용 프로필은 합성 가정이며 실제 비용 인수를 의미하지 않는다.
- 잠금 대상은 holdout4 + controls2 + realistic-costs1 = 7개다. 나머지 26개 결과의 성공·문제 없음·원장 대조 후에만 실행한다. 실제 잠금 접근 기능은 추가하지 않는다.
- 정책 2개를 비교하되 이미 고정한 정책을 자동으로 교체하지 않는다. 비교 결과는 설명 자료이며 실제 후보 선정으로 승격하지 않는다. fixed20 참조 재사용은 정확한 동일 입력 증거 없이는 하지 않고 모두 계산한다.
- 파일 소유권: planner는 conditional_plan.py/전용 테스트, execution은 conditional_execution.py/전용 테스트, fixture는 tests/research/conditional_fixtures.py, 메인은 conditional_runner.py·CLI·통합 테스트·문서를 담당한다.
- Orca Run `run_afd2af03c2db`에서 독립 작업 3개를 병렬 배정했다. 메인은 연결·통합을 진행한다. 모델은 수치 정확성과 경계 검증의 오류 비용을 고려해 Astra high, 정형 fixture는 Astra medium을 사용한다.
- 기존 미커밋 변경과 데이터 감사 자료를 보존한다. commit·push·DB·네트워크 수집·실제 잠금 열람은 범위 밖이다.

- 사용자 변경: 이후 모든 새 배정은 gpt-5.6-sol. 일반 구현·문서는 medium, 수치·잠금·복구·독립 검토는 high. 기존 Astra 3개는 최초 산출물까지만 유지하고 재배정하지 않는다. 팀장 세션 모델 변경은 사용자 설정 후 확인해야 하며 변경 완료로 추정하지 않는다.

- 후속 정정: 사용자가 Luna·Terra 제외 이유를 물어 취지를 재해석했다. Sol을 상위 모델로 두고 정형 탐색·문서는 Luna low/medium, 확정 명세 구현·테스트는 Terra medium, 통합·수치·잠금·복구·최종 검토는 Sol medium/high를 배정한다. Astra 자동 상향은 하지 않는다. Sol high 독립 검토는 이미 시작했으므로 유지한다.

- 검증: planner131개, executor27개, 통합28개 및 기존 회귀 포함 전체370개 통과(94.91초). 독립 검토는 Sol high, 최종 안내 문서 초안은 Terra medium으로 요청·실효 모델을 확인했다. 실제 CLI 합성33개 실행 성공. 후속 보고 표시·변조·실패 기록 보강까지 최종 재검증했다.

- 최종 독립 검토: Sol high 작성자 외 검토자가 두 Major 지적의 수정과 신규 테스트186개 통과(59.87초)를 확인했다. 잔여 Critical 0·Major 0. C0~C5 6/6·100% 완료. 실제 연구 완료는 아니며 다음 작업은 결과 문서 선택지에서 구분한다.
