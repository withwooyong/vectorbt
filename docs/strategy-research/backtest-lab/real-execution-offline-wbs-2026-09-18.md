# 실자료 도착 전 vectorbt 오프라인 준비 WBS

목적: ted-startup 데이터 전달과 무관하게 검증할 수 있는 `krx_lab` 가격 신호·시장 프로필 사전 검사·로컬 스냅샷 접근을 준비한다. 현재 판단: 이 오프라인 준비 범위는 검증을 마쳤으며 REAL 수익률 실행 차단을 유지한다. 범위: 순수 함수, 오프라인 고정 표본, 읽기 전용 로컬 로더, 문서·테스트. 한계: 실제 데이터 인수, 한국 시장 체결·비용 승인, 전략 수익률은 이번 완료 기준에 포함하지 않는다.

진행률: **100%** · 완료 **5/5** · 이 WBS의 남은 작업: 없음 · 실제 백테스트 차단: 전달 데이터 인수, 체결·비용 모델, REAL runner와 독립 장부 검증. 아래 진행률은 검증을 마친 항목의 가중치 합으로 계산하며 실제 백테스트 완료율이 아니다.

## 판단과 검증 기록

- 모든 도구는 로컬 입력만 읽으며 DB·네트워크 연결, 가격 정정, 실자료 수익률을 수행하지 않는다.
- REAL runner와 실제 체결 모델은 전달 데이터와 날짜별 시장·비용 근거가 검증된 뒤에만 열린다.
- 병렬 담당은 신규 파일을 각자 소유하고, 메인이 로더·문서·통합을 맡는다.
- 독립 검토에서 종목코드 재사용·비활성 구간의 신호 이력 혼합과 조정계수·기업행사 연결 진단 문제를 발견해 수정했다. 두 회귀 사례와 먼 날짜 기업행사 사례를 추가했다.
- 오프라인 고정 표본 관련 테스트 17개, 전체 `tests/research` 393개, 변경 파일 Ruff 검사와 `git diff --check`를 통과했다. 전체 시장 규모의 C1 인라인 가격 메모리 상한은 측정하지 않았으며 데이터가 온 뒤 분할 입력 계약을 정해야 한다.
