# v3 데이터 기반 56개 전략 백테스트 인수인계

목적: 다음 세션이 ted-startup의 추가 작업을 다시 전제하지 않고 vectorbt에서 56개 전략의 실데이터 백테스트를 완성하도록 현재 결론과 미완료 작업을 구분한다. **현재 판단:** ted-startup의 PostgreSQL `2014-2023-v3`를 입력으로 구현을 시작한다. 아직 56개 실데이터 결과는 없으며 실거래 적합성도 검증되지 않았다. 범위는 2014년 준비기간과 2015-06-15~2023-12-31 정규장 KOSPI·KOSDAQ 보통주다. 2024년 이후 잠금 구간과 실제 주문은 범위 밖이다.

## 먼저 지킬 결론

- 우선순위는 기존 12개 진입 × 4개 청산 = **48개**, 상대거래량 2개 진입 × 같은 4개 청산 = **신규 8개**, 합계 **56개 전체 비교**다. OBV 8개와 거래량 위축 8개는 독립된 후속 실험이며 기본 56개에 섞지 않는다.
- 56개 진입 신호는 완료된 수정 OHLC와 원거래량으로 계산한다. 배당금·업종·시가총액·재무·뉴스는 이 신호의 입력이 아니다. `t`일 신호에 `t+1` 정보를 사용하지 않는다.
- 사용자가 요청한 것은 1억 원으로 최대 20종목에 분산하는 백테스트다. 기존 문서·코드에 있는 **업종별 25% 상한은 상한가나 익절 기준이 아니며, 사용자가 이번 56개 비교의 필수조건으로 정한 것도 아니다.** 실행 전 새 실험 버전에서 이 상한을 사용하지 않도록 정책·코드·테스트를 명시적으로 맞춘다. 기존 v1 결과와 동일한 계약이라고 주장하지 않는다.
- 데이터 수집·정정은 ted-startup의 범위이고, vectorbt는 읽기 전용으로 v3를 소비한다. **현재 확인된 사실만으로 ted-startup에 10,813건 전수 재분류나 새 revision을 선행 요청하지 않는다.** 실제 신호·주문·보유에 영향을 주는 미확정 사례가 검증 중 발견되면 그 키와 필요한 판정만 좁혀 요청한다.
- 무거래 또는 시가가 0인 날에는 주문을 체결하지 않는다. 해당 날짜를 정상 봉으로 간주하거나 전일값으로 채우지 않는다. 보유 중 발생한 미확정 사건·평가·청산은 별도 상태로 기록하고 그 영향이 해결되기 전 확정 성과나 실거래 적합성을 주장하지 않는다.
- 수정주가 기반 전략 비교와 실제 원화 정수주 계좌 손익은 다른 결과다. 실제 보유 주수·현금 장부가 기업행사에 영향을 받으면 v3의 사건 자료를 사용한다. **현금배당은 56개 전략의 진입·청산 조건이 아니다.**

## 확인된 입력과 현재 구현 상태

ted-startup의 원천 계약 v2 문서는 별도 저장소에 있으므로, 실제 소비 계약은 운영 DB와 로컬 코드에서 재확인한다. 이전 읽기 전용 감사에서는 dataset `krx-backtest-source`, revision `2014-2023-v3`, SHA-256 `e95066aa516971ff63e4d6da19a7639b0eab18783eca159a428dc268a2bd13c2`, `SEALED`를 확인했다. 이 값은 인수 시 재검증해야 하며 데이터 존재와 REAL 실행 허가는 별개의 판단이다.

현재 [전략 코드](../../../research/krx_lab/strategies.py)는 기존 12개 진입만 구현한다. [실행 코드](../../../research/krx_lab/runner.py)는 REAL 입력에 `REAL_EXECUTION_NOT_ADMITTED`를 발생시키며 합성 경로만 실행한다. [계좌 코드](../../../research/krx_lab/execution.py)는 업종 25% 상한을 아직 적용한다. 따라서 **데이터 납품은 완료됐지만 vectorbt의 REAL 어댑터·실행·신규 8개·검증은 미완료**다. 가드를 임의로 제거해 미검증 수익률을 만들지 않는다.

이전 감사의 보수적 1,891종목 부분집합에서는 평가기간 원가격 3,228,511 종목일 중 시가·고가·저가 0과 무거래가 겹치는 10,843건을 확인했다. 10,813건은 별도 상태 표기가 없었고, 거래량 양수인데 원가격 시가·고가·저가 0인 2건(`047810` 2017-10-11, `060570` 2017-07-17)도 있었다. 이 수치는 **전체 모집단의 결함 수가 아니며**, 곧바로 전체 실험 차단이나 ted-startup 재작업 규모를 뜻하지 않는다. 거래 불가 판정과 영향받는 포지션의 확정 성과 판정을 분리한다.

## 다음 작업 순서와 완료 기준

1. 현재 dirty worktree를 보존한 채 v3 revision·member·기간·raw/adjusted OHLCV 및 기존 제외 사유를 읽기 전용으로 다시 대조하고, 실행 입력의 hash·SQL·범위를 고정한다.
2. 56개 실행 계약을 결과 보기 전에 새 버전으로 고정한다. 업종 상한 제거, 1억 원·최대 20종목, 원거래량 하한, 250봉 준비, 다음 공식 거래일 시가, 네 청산, 키움 수수료 가정과 날짜별 매도세, 무거래·결측·기업행사 영향 처리 및 결과 등급을 명시한다.
3. v3 어댑터, 상대거래량 2개 진입, REAL runner를 구현하고 관련 회귀를 통과시킨다. 기존 48개 합성 경로·잠금 구간 보호·원장 불변식을 훼손하지 않는다.
4. 작은 실데이터 smoke → 56개 전체 개발·검증 구간 순서로 실행하고 성공·0거래·미확정·차단 결과를 모두 보고한다. 실행 완료, 전략 유효성, 실거래 승인 및 신규 전략 발굴은 서로 다른 상태로 유지한다.

**사용자 운영 요구:** 작업 전 범위·변경 파일·예상 시간을 먼저 보고하고, 오래 걸리면 중간 진행 상황을 알린다. ted-startup에서 실제로 빠진 필수 자료가 발견될 때에는 영향 키·필요성·대안을 확인한 후 사용자에게 그대로 전달 가능한 좁은 작업요청 프롬프트를 제공한다. `AGENTS.md`는 사용자의 명시적 요청 없이 수정하지 않는다. 현재 작업 폴더에는 다른 미커밋 변경과 조사용 임시 HTML이 있으므로 무차별 `git add -A`, reset, clean을 하지 않는다.
