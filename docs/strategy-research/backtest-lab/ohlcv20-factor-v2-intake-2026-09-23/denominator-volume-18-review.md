# 계수 v2 우선 18키: 배정 분모와 거래량 조정 단위 검증

18키를 보존 공식 원문과 현행 정책·코드로 검증했다. **17키는 배정비율 분모를 확인했으며, 영풍제지 006740/2023-04-19는 이미 소각한 자기주식의 재차감 위험으로 미확정이다.** 17키는 자기주식 제외 16키와 의결권주식 명시 1키다. 18키 모두 현행 거래량 미승인을 유지한다. 총발행주식 기준 계수와 가격 역산값의 근접성은 거래량 단위 승인 근거를 대신하지 않는다.

범위는 기존 104키 감사의 일반 분모 차이 45키 중 `impact-v2.signal_eligible_dependency_days > 0`인 18키다. 신호 준비 의존성으로 고른 조사 대상이며 실제 신호·거래 발생을 뜻하지 않는다. 기준일 2026-09-23, 사건 범위 2016~2023년. DB 접근·백테스트·신호 함수 실행·정책/원자료/코드 수정·커밋·푸시는 수행하지 않았다. 기존 로컬 자료를 읽었고, 공개 DART 필드 가이드와 KRX 제도 설명만 웹에서 보조 확인했다. API 수집이나 새 가격 데이터 취득은 하지 않았다.

먼저 단위 구분을 읽으면 두 계수가 왜 달라지는지 알 수 있다. 18키 표는 분모의 직접 근거와 산술을 제시하고, 예외 절은 수치 일치만으로 확정하면 안 되는 사례를 설명한다. 끝에는 현행 정책 아래의 판정, 검증 근거와 재개 조건을 기록했다.

## 1. 배정 대상 기준과 총발행주식 기준은 분모가 다르다

`T`는 사건 전 보통주 발행총수, `N`은 공시 신주/배당 보통주 수, `E`는 배정 대상 보통주 수, `X`는 배정에서 제외되는 자기주식 수, `r`은 적격 보유 1주당 배정되는 신주 수다. 공시 계획 수량을 사용했으며 실제 발행완료 수량은 검증하지 않았다.

| 값 | 산식 | 뜻·단위 | 확인 범위 |
| --- | --- | --- | --- |
| 주주 배정비율 | `r ≈ N/E` | 배정 대상 기존 1주당 신주 수 | 17키의 E는 원문 또는 원문 T−X로 확인. 표시 정밀도·정수화 잔차 있음 |
| 주주 기준 수량계수 | `H = 1+r` | 적격 주주의 사건 전 1주를 사건 후 주식 수로 환산하는 계수 | 현행 거래량 정책의 기대계수 |
| 총발행주식 기준 계수 | `G = 1+N/T` | 전체 보통주 발행총수의 증대비율 | H와 의미가 다른 분석용 비교값 |
| 가격 역산계수 | `B = anchor_close/reference_price` | 공식 기준가격 조정의 역수 | 주주 배정 분모나 실거래량 단위를 단독 입증하지 않음 |

자기주식이 배정에서 제외되면 `E=T−X<T`이므로 일반적으로 `H>G`다. 소수점 표시와 단수 처리 때문에 `N=rE`의 정확한 등식까지 강제하지 않는다. [DART 무상증자 API 가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS005&apiId=2020024)도 신주 수, 증자 전 발행총수, 1주당 배정주식 수를 별도 필드로 정의한다. API 가이드 자체가 개별 사건의 E나 거래량 조정 정책을 정하는 것은 아니다.

## 2. 거래량 코드는 과거 주식 수를 당일 기준으로 환산한다

공급자 정책 `ALLOTMENT_RATIO_PARSED_FROM_DART_IS_DIRECT_EVIDENCE`는 `H=1+r`와 B의 상대차가 0.5% 이내일 때만 H를 거래량 계수로 전달한다. 다른 공식 총주식 수가 맞아도 이 비교를 통과하지 못하면 차단한다. 이번 18키는 모두 실패하고 `volume_factor`는 미승인이다.

소비자 `research/krx_lab/ohlcv20_signal.py:217`의 산식은 `V_adjusted(s→t)=V_raw(s)×∏volume_factor(e)`이며 `s<e≤t`인 사건에만 곱한다. 당일 기준으로 환산한 전일 거래량과 당일 원거래량을 비교하여 `V_today ≥ 2×V_previous_adjusted`를 검사한다(`:241`). 따라서 정책상 단위는 주주 배정비율에 따른 환산 주식 수다. 원체결 주식 수, 거래대금 또는 총발행주식 대비 회전율을 새로 정의하거나 고치는 연산은 아니다.

권리락일 적용은 현행 코드 계약이다. 신주상장일의 실제 유통 가능 수량이나 개별 보유자의 수령 완료를 의미하지 않는다. `ohlcv20_input.py:175`는 거래량 승인 플래그를 검사하지만 조정 거래량 시계열을 직접 만들지 않는다. 이번에는 두 함수 모두 실행하지 않고 읽어서 검증했다.

가격계수 `P=reference_price/anchor_close=1/B`와 거래량 H는 서로 다른 분모를 반영할 수 있다. `P×H`가 반드시 1이거나 조정 가격×조정 거래량이 원거래대금과 같아야 한다고 가정할 근거가 없다. [KRX 기준가격 설명](https://regulation.krx.co.kr/contents/RGL/03/03010100/RGL03010100T6.jsp)은 기업행사에 따른 이론가격 조정과 호가단위 처리를 설명한다. 개별 18건의 당시 호가단위·최종 사건 수량을 모두 재현한 것은 아니므로 G와 B의 작은 잔차를 전부 호가 반올림이라고 확정하지 않는다.

## 5. 예외와 미확정 사항

- **영풍제지 006740/2023-04-19:** 원문은 `22,295,000−2,313,838=19,981,162`로 이미 소각한 자기주식을 차감하여 T를 설명한다. 그런데 `N/r=17,667,324`는 그 T에서 소각 수량을 다시 뺀 값이다. 원문에 재차 배정 제외 근거가 없으므로 E를 확정하지 않는다. G가 B와 근접한다는 사실도 이 내부 불일치를 해소하지 못한다. 원공시·소각·정정·최종 발행수량의 연결을 공급자 측에서 추가 확인해야 한다. 보존 목록 `data/sources/dart/full-plan-major-2015-2023/raw/list_responses/006740_page1.json`에서 2023-04-06 정정 접수번호 `20230406002900`을 확인했다. 접수번호로 좁게 검색한 저장 파일 목록에서는 정정 원문을 찾지 못했다. 목록의 존재만 확인했으며 정정 내용·효력은 미확정이다. 기존 45키 원인 분류는 산술상 분류로 보존하고 이번 의미 검증에서 1키의 예외를 명시했다.
- **모두투어 080160/2017-06-21:** E=11,898,431은 의결권 있는 주식 수로 직접 명시됐다. `T−E=701,569`를 자기주식이라고 부를 직접 근거는 이번 원문에 없다. `N−rE=+0.9064735주`로 표시 비율의 유한 정밀도와 양립하지만 반올림·절사 방식은 확정하지 않는다.
- 나머지 확인 16키의 잔차 `N−rE`는 9키가 0이고 7키가 −0.04~−0.8주다. 7키에는 단주/단수주 현금처리 문구가 있다. 계획 수량의 정수화와 양립하지만 실제 주주별 정산이나 최종 발행완료 증거는 아니다.
- 085370과 290510 원문에는 종류주식도 있으므로 보통주 T/N만 사용했다. 종류주식을 합한 총수로 분모를 바꾸지 않았다.

## 6. 정책을 유지한 판정과 다음 작업

확인한 17키의 직접비율 파싱값을 G−1로 고치는 것은 원문 오류 정정이 아니다. 분모를 변경하는 것이므로 현행 정책 아래에서 허용할 수 없다. 006740은 자료 내부 관계를 더 검증할 대상이지만 이번에 원문이나 파서를 고칠 근거는 확보되지 않았다. 허용오차 확대, 계수 승인 승격, 정책 개정은 수행하지 않았다.

현재 상태는 18키 전부 `price_admitted=true`, `volume_admitted=false`, `signal_admitted=false`다. 전체 v2 가격 643/733·거래량 539/733의 기존 부분 승인도 그대로다. 백테스트를 하지 않았으므로 실제 신호·주문·보유·수익률은 계산하지 않았다.
