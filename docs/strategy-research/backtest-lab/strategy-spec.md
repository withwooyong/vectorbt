# 최대 1개월 보유 기술진입 연구 명세

이 문서는 1억 원 단일 공동계좌로 여러 기술진입과 사전 확정 익절·손절·만기 규칙을 비교하기 위한 **연구 설계**다. 12개 진입 × 4개 청산의 48개 1차 후보를 전부 저장한 뒤, [기술 명세](technical-spec.md)의 사전 선정 기준으로 한 개만 고르거나 `NO_SELECTION`을 낸다. 최근 저장된 관측에서 가격 계보·역사 종목·기업행사·정지의 인수가 미완료이며, 이 명세는 수익성·HTS 일치·실주문을 주장하지 않는다.

최대 보유는 2~5거래일이 아니라 **달력 기준 최대 1개월**이다. 초기자금 100,000,000원만 쓰고 인출·외부 현금은 0원으로 둔다. 사용자가 별도로 언급한 1~2억 원의 여유자금은 계좌·성과·리스크 계산에서 제외한다.

## 1. 실행 전 데이터 게이트와 범위

| 항목 | 1차 연구 계약 | 현재 상태와 처리 |
| --- | --- | --- |
| 관측 범위 | 일봉 `2015-01-02`~`2026-09-10`, OHLCV와 공식 거래일 달력 | 조정가격(`adjusted`)만 확인됨. 가격 계보·역사적 universe는 미해결 |
| 사용 가능 판단 | 각 종목·각 봉의 날짜, OHLCV, 거래정지, 기업행사 상태를 입력 manifest에 고정 | 누락·0·중복·비양수·OHLC 관계 위반은 보정·전일값 채움 없이 해당 주문/평가를 `unsupported`로 기록 |
| 역사적 대상 | 해당 시점의 보통주·업종 분류를 보존한 universe | 당시 KOSPI·KOSDAQ 보통주가 기본 제안. 현재 master만 있으면 탐색 등급만 허용하고 운용 적합 선정은 차단 |
| 가격 의미 | 신호 조정계열과 raw 체결/정수주 계열의 대응 계수·기업행사를 명시 | 조정가격의 배당·분할 반영 방식은 미확정. 실제 주수·세금·총수익률 해석 금지 |

데이터 사용 등급 SYNTHETIC/EXPLORATORY_ADJUSTED/EXECUTION_ELIGIBLE와 BLOCKED 판정은 [기술 명세](technical-spec.md)를 따른다. 정확한 1억 원 정수주 성과는 raw·기업행사 인수 후에만 해석한다.

입력 상태는 `valid`, `missing_ohlcv`, `suspended_or_no_open`, `corporate_action_unknown`, `calendar_unknown` 중 하나로 장부에 남긴다. 기업행사 상태가 미확정인 보유분은 수량·가격을 임의로 환산하지 않고 확정 성과에서 제외한다.

현재 구현된 예제는 단일 종목과 10개 관측봉 청산의 기준선뿐이다. 이 문서의 공동계좌·달력 1개월·손절/목표가 계약은 그 예제의 동작 주장이나 코드 변경 지시가 아니다.

## 2. 시간·가격·체결 계약

`t`는 완료된 공식 거래일이고, `O_t,H_t,L_t,C_t,V_t`는 해당 일봉이다. 지표와 후보 판단은 `t` 마감 뒤에만 한다. `ATR14_t`는 true range의 14봉 단순평균이며, RSI는 Wilder RSI(14), Bollinger 표준편차는 20봉 `ddof=0`, MACD는 EMA(12)−EMA(26)과 그 EMA(9)다. 창 부족·입력 불명은 신호가 아니다.

지표 초기값: True Range는 max(H−L, abs(H−전일C), abs(L−전일C)); 전일C가 없으면 해당 TR은 미확정이다. ATR은 유효 TR 14개의 단순평균이다. RSI는 최초 14개 등락의 상승/하락 단순평균으로 시작하고 이후 Wilder 계수 1/14로 갱신한다. 평균 상승·하락이 모두0이면 RSI=50, 하락만0이면100, 상승만0이면0이다. EMA_n은 최초 n개 종가 SMA로 시작하고 계수 2/(n+1)을 적용한다. MACD 신호 EMA9도 최초9개 유효 MACD 평균으로 시작한다. 공통 평가 준비250봉, 일자축·NaN 전파 규칙은 기술 명세를 따른다.

당일 아직 확정되지 않은 H/L/C/V로 시가 진입 가능 여부를 결정하지 않는다. 시가 이후 데이터가 누락되면 해당 보유의 평가·청산이 불명확한 것으로 기록하고 선정 적격을 차단한다. 사후에 그 진입을 없애 유리한 성과를 만들지 않는다.

공통 거래량 조건은 `V_{t-1} >= 100,000`이다. 이는 원단위·역사적 유동성 의미를 확인해야 하는 고정 floor이며, 후보 간에 최적화하거나 별도 임계값 탐색을 하지 않는다.

### 다음 시가 진입 가격

신호가 참이면 `t` 마감 시 아래 세 가격을 먼저 고정한다. `A=ATR14_t`이고 `B_t=min(C_t+0.5A, 1.01C_t)`는 다음 날 매수 상한이다.

| 청산군 | 절대 손절 `S_t` | 절대 목표 `T_t` |
| --- | ---:| ---:|
| PCT_3_6 | `0.97C_t` | `1.06C_t` |
| PCT_5_10 | `0.95C_t` | `1.10C_t` |
| ATR_1_5_3 | `C_t−1.5A` | `C_t+3A` |
| ATR_2_4 | `C_t−2A` | `C_t+4A` |

실제 운용 검증에서는 S·T·B를 같은 날 원가격 단위로 대응시킨 뒤, 해당 일자 호가단위로 손절 S는 내림·목표 T는 올림·진입 상한 B는 내림하여 계획에 저장한다. 반올림 뒤 가격 관계와 위험을 다시 검사한다. 조정비율을 알 수 없으면 정수주 운용 검증을 차단한다.

`t+1`의 공식 거래일 시가 `O`에서만 신규 주문을 판정한다. `0 < S_t < O <= B_t < T_t`, 현금·슬롯·위험 한도, 데이터 게이트를 모두 통과하면 `O`에 매수한다. 하나라도 실패하면 당일 취소하며 장중 `B_t` 도달을 기다리거나 다음 날로 이월하지 않는다. 따라서 신호 당일 종가 체결과 미래 봉 참조는 없다. 지연2 스트레스는 동일 t의 가격 계획을 유지한 채 t+2 공식 거래일 시가에서 한 번 시도하며, 만기는 실제 진입일에서 계산한다. 미래 가격에 맞춰 계획을 다시 만들지 않는다.

### 보유 중 청산 우선순위

1. 만기일이면 **시가 우선**으로 `O`에 청산하고 그 날의 고가·저가 손절/목표 판정은 하지 않는다.
2. 만기가 아닌 날, `O <= S_t`이면 gap-stop으로 `O`에 청산한다. 불리한 gap을 손절가로 채우지 않는다.
3. `O >= T_t`이면 목표 limit의 보수적 체결가 `T_t`로 청산한다. `O`의 더 유리한 체결은 별도 민감도 결과로만 저장한다.
4. 그 밖에는 `L <= S_t`이면 `S_t`, `H >= T_t`이면 `T_t`에 청산한다. 같은 봉에서 둘 다 닿으면 일봉으로 순서를 알 수 없으므로 **손절 우선**이다.

진입일도 위 순서를 적용해 `O` 매수 뒤 고가·저가를 검사한다. 이 순서는 시가 진입과 같은 날 목표/손절이 동시에 가능한지, 손절·목표의 체결가가 무엇인지 검증 장부에 남긴다.

### 달력 1개월 만기와 거래정지

진입일 `d`의 만기는 `d + 1 calendar month`이며, 원일이 다음 달에 없으면 그 달의 말일로 clamp한다. 그 날짜가 공식 거래일이 아니면 그보다 작거나 같은 가장 최근 공식 거래일의 시가에 청산한다. 예: 1월 31일 진입은 2월 말일, 주말이면 직전 공식 거래일이 기준이다.

만기에 거래정지·결측으로 시가 체결이 불가능하면 만기 위반 예외를 장부에 기록하고, 다음 체결 가능한 공식 거래일마다 시가 청산을 재시도한다. 포지션을 0으로 평가하거나 마지막 가격으로 강제청산하지 않는다. 평가가격도 없으면 확정 성과에서 제외하고 stale 평가 상태를 남긴다.

## 3. 1차 진입 카탈로그: 12개 × 4개 청산

모든 식은 `t` 종가 기준이며 다음 시가에만 실행한다. 등호·창 포함 여부는 아래 각 식을 그대로 적용한다. 모든 교차를 하나의 공통 cross 함수로 간주하지 않는다. 앞의 거래량 floor도 모두 적용한다.

| 군 | 두 후보의 정확한 신호 | HTS 상태 |
| --- | --- | --- |
| CROSS | `SMA5(t-1)<SMA20(t-1) ∧ SMA5(t)>SMA20(t)`; 같은 식의 SMA5를 SMA10으로 교체 | 기존 조건 대응 후보, 실제 HTS 일치 미검증 |
| BREAKOUT | `C_t > max(C_{t-20}…C_{t-1})`; 같은 식의 20을 60으로 교체 | 기존 조건 대응 후보, 실제 HTS 일치 미검증 |
| TREND_PULLBACK | `C_t>SMA60_t ∧ 100(C_t/C_{t-3}-1)<=-3`; 같은 식의 −3을 −5로 교체 | 기존 조건 대응 후보, 실제 HTS 일치 미검증 |
| RSI_REENTRY | `C_t>SMA60_t ∧ RSI14_{t-1}<30 ∧ RSI14_t>=30`; 30을 40으로 교체 | **Python 전용**, HTS 대응 미확인 |
| BOLLINGER_REENTRY | `C_t>SMA60_t ∧ C_{t-1}<Lower20_{t-1,k} ∧ C_t>=Lower20_{t,k}`; `k=1.5, 2.0` | **Python 전용**, HTS 대응 미확인 |
| MACD_CROSS | `C_t>SMA60_t ∧ MACD_{t-1}<=Signal_{t-1} ∧ MACD_t>Signal_t`; SMA60을 SMA120으로 교체 | **Python 전용**, HTS 대응 미확인 |

따라서 12개 진입과 위 4개 청산군의 직교 조합은 48개 primary variant다. 이전 연구의 3군×2개·10관측봉 청산 기준선은 별도 역사 비교로 저장할 수 있으나, 이 48개 중 선정하거나 경쟁시키지 않는 `not_eligible_baseline`이다.

## 4. 공동계좌·주문량 계약

| 항목 | 연구 기본값 (투자 승인 아님) |
| --- | --- |
| 초기자금·현금 | 100,000,000원, 인출 0원·외부 입금 0원. 직전 거래일 계좌가치만 재투자 |
| 보유·배분 | 최대 20 슬롯, 목표 총투자 80%, 슬롯당 목표 4%, 종목당 상한 5%, 업종 합산 상한 25% |
| 위험 | 한 신규 거래의 계획 손실 상한은 직전 계좌가치의 0.5%: `q*(O−S_t+예상 왕복 주당비용)<=0.005E_{t-1}`. 갭으로 실제 손실이 더 커질 수 있음 |
| 수량 | `q`는 목표금액·종목상한·위험상한·비용포함 가용현금·직전20거래일 평균 원거래량의0.1% 중 최소치로 산출한 정수주. 0.1%는 연구 제안이며 당일 총거래량으로 수량을 정하지 않음. `q<1`은 거절 |
| 동시성 | 보유, 당일 체결 예정, 만기 위반 재시도 포지션의 합집합이 슬롯을 점유. 매도 처리 뒤 매수 후보를 계산 |
| 후보 초과 | `SHA256("lab-v1|20260913|" + signal_date + "|" + code)` 오름차순, 해시 동률은 종목코드순. run/전략/비용과 무관한 고정 seed로 후보 우선순위를 동일하게 유지; 수익·미래 정보 순위 아님 |

업종 분류가 해당 시점에 없으면 25% 검사를 통과시켰다고 가정하지 않고 실행을 막거나 `sector_unknown`으로 분리한다. 같은 종목의 추가 매수와 같은 날 어떤 사유로든 청산한 종목의 재진입은 금지한다. 외부 여유자금 1~2억 원, 신용·레버리지·공매도·분수주는 사용하지 않는다.

공통 민감도 비용은 거래대금의 편도 10/30/50bp를 `fees` 한 필드로만 적용하며 슬리피지는 0으로 별도 더하지 않는다. 이는 실제 수수료·세율이 아닌 민감도 가정이다. 다만 앞 절의 gap-stop과 보수적 목표 limit 체결가는 일봉 가격 경로 가정으로 비용과 이중 계산하지 않는다.

성장 배분은 1차 48개 선정 뒤의 별도 2차 실험이다. 고정 20슬롯의 notional 성장과 `1.5억 미만 10→1.5억 이상 15→2억 이상 20` 슬롯 단계 성장만 비교 예시로 두며, 20을 넘기지 않는다. 기술 후보 고정 뒤 정책만 비교하고 잠금 전에 선택을 고정한다. 실거래 승인은 아니다.

## 5. 구간·시나리오·선정 기록

| 구간/시나리오 | 목적과 저장 단위 |
| --- | --- |
| 2015~2019 | 개발·데이터 게이트 점검. 조정가격/역사 universe가 미해결이면 `BLOCKED` 사유도 저장 |
| 2020~2023 | 4개 연도 validation fold. delay 1의 48개×비용 3개×4년=576 결과와 delay 2·30bp의 48개×4년=192 결과, 합계 768개를 모두 저장 |
| 2024-01-01~2026-09-10 | 잠금 예정 구간. 과거 사용 이력을 먼저 확인하고, 본 뒤 규칙을 바꾸면 잠금 검증으로 부르지 않음 |
| 최종 holdout | 사전 선정된 한 후보에 비용 10/30/50bp와 delay 2를 포함한 네 조건을 별도 보존 |

각 결과는 성공·실패·0거래를 빠짐없이 저장한다. 최소 장부는 데이터/코드 해시, 입력 상태, universe·업종 버전, variant·청산군, signal/entry/exit/만기일, 각 가격과 체결 사유, 거절·만기위반, 비용, 일별 현금·평가·미청산 상태다. 수익률 위험지표의 연환산은 거래일 252일, CAGR은 실제 달력 경과일/365.25로 고정한다.

선정의 순위, 비용·지연 통과 여부, `NO_SELECTION` 조건은 이 문서에서 새로 만들지 않는다. [기술 명세](technical-spec.md)에 사전 고정한 선정 규칙을 참조하고, 그 규칙이 아직 없거나 데이터 게이트가 막히면 `NO_SELECTION` 또는 `BLOCKED`로만 종료한다.

선정 후보에는 실제 날짜별 비용 프로필과 선택 후보의 일봉 충돌 상한 민감도를 추가한다. 기준/추가 실행 수와 선정 차단 기준은 기술 명세 5~6절을 따른다.
