# 거래소 제도 변경·수집·백테스트 검토 WBS

목적: 2026-09-14 KRX/NXT 변경이 수집과 연구 실행에 미치는 영향 및 PostgreSQL의 현재 인수 가능 수준을 판단한다. 현재 판단은 수집 지속 확인, 정식 연구 실행 차단이다. 최신 기간은 가격 값 없이 거래소·건수·시각 메타데이터만 확인하고 2015~2023 가격 품질은 읽기 전용 검사한다. 수집·정정·배포·실제 수익률 실행은 범위 밖이다.

검토 진행률 **100% · 4/4 완료**. 남은 검토 작업 없음. 실제 연구 차단: 가격 세션 정의·signal 사본 정리·실자료 어댑터와 기업행사/비용 인수 미완료.

## 실행 기록

- 기존 사용자 변경과 미추적 파일을 보존한다. 작성 파일은 이 검토 디렉터리에 한정한다.
- 독립 작업을 병렬 배정했다. 기존 Sol 검토 에이전트를 재사용하고 Terra는 ted-startup 코드를 읽기 전용 검토한다. 메인은 공식 자료와 DB를 확인한다.
- 최신 HANDOFF는 kiwoom 상장 전 8,937행 격리 완료, signal 사본 6,093행 격리 미배포를 기록한다. 이전 699행은 현재 DB 재측정 전의 기록으로 취급한다.
- [통합 결과](README.md)에 공식 출처 접근 수준, 최신 일봉·분봉 범위, 원천 699→4 개선, signal 6,093행과 상태 불일치 1,003행을 기록했다. 총 24개 읽기 전용 검사와 영수증·SQL·stdout/JSON·파일 해시 검산 및 수치·문서 링크·공백 검사를 통과했다.
- 최종 독립 검토 Sol high: Critical 0 / Major 0. 수치·SQL·stdout/JSON·영수증·해시·기간 제한과 과도한 인수 주장 없음 확인. 로컬 보고서 산출물 검증으로 완료했으며 전체 백테스트 준비 완료를 뜻하지 않는다.
