# 9월 14일 제도 변경 검토: 수집은 이어지지만 백테스트 인수는 미완료다

**2026-09-16 10:12~10:14 KST 실측 결론:** ted-startup은 변경 후 KRX·NXT 일봉을 계속 저장하며 KRX 애프터마켓 분봉도 수집하고 있다. 수집 중단으로 판단할 근거는 없다. 그러나 **일봉의 정규장/애프터마켓 집계 정의, 분봉의 하루 지연, signal 사본 품질과 vectorbt 실제 실행 지원이 남아 있어 정식 백테스트 인수는 `BLOCKED`다.**

검토 범위는 공식 제도 안내, ted-startup 코드·배포된 scheduler 파일, home PostgreSQL 두 DB와 vectorbt 연구 실행 계약이다. 2024년 이후에는 가격·수익률 없이 건수·거래소·시각만 조회했고, 가격 품질 검사는 2015~2023으로 제한했다. 주문·수집·DB 정정·배포·실제 수익률 실행은 하지 않았다. 현재 장중 9월 16일 일봉이 없다는 것을 누락으로 세지 않는다.

아래는 제도와 수집의 연결을 먼저 설명하고, DB 현황에서 현재 확인한 수준을 제시한 뒤 백테스트 영향과 조치 순서를 정리한다. 끝에는 재현 SQL·검증 및 접근 한계를 남긴다.

## 1. 제도 변경은 거래시간뿐 아니라 체결·주문 유효성도 바꾼다

**2026-09-14부터 KRX는 16:00~20:00 접속매매 애프터마켓을 신설하고 기존 16:00~18:00 시간외단일가를 폐지했다.** 정규장은 09:00~15:30을 유지한다. 정규장 미체결 주문은 KRX 애프터마켓으로 자동 이전되지 않으며 ETF·ETN, 관리·투자경고 등 제외종목이 있다. 따라서 모든 종목을 20시까지 동일하게 거래 가능한 것으로 모델링하면 안 된다. [KB증권 공식 안내 — opened](https://m.kbsec.com/go.able?idt=20260904&linkcd=s060300010000&seq=10010298)

**NXT는 정적 변동성완화장치(VI)와 단일가 체결을 도입했다.** VI 시 2분 단일가 전환, 시장 중단·중요공시 정지 후 재개 시 단일가 적용, 프리마켓에서만 유효한 GTP 주문은 08:50 미체결잔량 취소가 주요 변경이다. 같은 고가·저가를 관측해도 즉시 주문 체결을 보장하지 않는다. 이번 검토의 제도 본문은 증권사 공식 시행 안내로 확인했다. KRX 보도자료 페이지는 열렸지만 해당 공지 본문이 동적으로 표시되어 확보되지 않았고, NXT 공식 공지 본문도 확보하지 못했다. 증권사별 SOR(최선집행을 위한 자동 주문 분배) 세부 기준을 전체 시장 공통 규칙으로 일반화하지 않았다. 일부 일반 안내 페이지에는 변경 전 시간표가 남아 있으므로 시행일이 명시된 공지를 우선했다.

## 2. 수집은 진행되며 새 애프터마켓도 관측된다

## 3. 문제없다고 선언하기 전에 해소할 수집 위험

**가장 큰 위험은 날짜가 같아도 가격의 의미가 달라질 수 있다는 것이다.** KRX 일봉이 정규장 기준인지, 정규장과 애프터마켓을 합친 것인지 API 응답 정의를 이번에 확정하지 못했다. 고가·저가·거래량과 종가의 집계 범위가 서로 다를 수도 있다. 9월 14일 이후 신호를 기존 일봉과 연결하기 전에 이를 데이터 계약으로 고정해야 한다.

| 위험 | 확인한 근거 | 필요한 확인·조치 |
| --- | --- | --- |
| 일봉 세션 정의 미확정 | 날짜·종목·수정 여부 키만 있고 regular/after 구분 없음 | ka10081 공식 정의와 원문·분봉 집계 대조, 가격 확정 시각 명시 |
| 거래소 합성 뷰 오해 | `stock_price_combined`는 COALESCE로 KRX 값을 우선하며 양 시장 거래량을 합산하지 않음 | 통합시장 OHLCV로 사용 금지, KRX 우선 fallback임을 소비 계약에 명시 |

## 4. PostgreSQL 품질은 개선됐지만 source와 signal 인수 상태가 다르다

**이전 699행 문제의 핵심은 가격 복원이 아니라 상장 전 허수 격리로 해소됐다.** kiwoom 격리 테이블에서 **8,937행·14종목**을 확인했다. 2015~2023 수정주가 `TRADED` 중 KIWOOM 비양수·OHLC 모순은 이제 **0행**, KRX는 **4행**이다. 수정주가 전체는 6,100,885행이다. 전날의 “102950 결손 695행 지속” 판단은 현재 상태에 적용하지 않는다.

KRX 4행은 ted-startup 감사에서 거래정지일 시간외 대량매매의 OHL 0 표기라고 설명했다. 이번 DB에는 여전히 `TRADED`이고 일반 일봉 체결 가격으로는 부적합하므로 공식 근거와 거래 상태·체결 정책에 연결해야 한다. 오류 가격을 억지로 복원하거나 일괄 제거할 대상이라고 단정하지 않는다. [원천 격리 ADR](</C:/Users/aeby/vscode/ted-startup/docs/ADR/ADR-0009-pre-listing-phantom-rows.md>) 및 [감사 설명](</C:/Users/aeby/vscode/ted-startup/docs/data-quality/pre-listing-audit-2026-09-15/README.md>)을 근거로 구분했다.

**signal 사본은 아직 같은 수준으로 정리되지 않았다.** 운영 migration은 `028_stock_price_state`이며 029 격리는 미적용이다. 12종목 상장 전 허수 **6,093행**을 DB에서 재확인했다. KIWOOM 원천 정리만으로 이미 이관된 signal 행이 자동 제거되는 구조는 아니다.

또한 signal의 2015~2023 `TRADED`에서 비양수 OHL·OHLC 모순 **1,007행·23종목**을 확인했다. 이 중 **1,003행은 거래량 0·종가 양수**이며 나머지 4행은 앞의 KRX 대량매매 표기다. 1,003행을 모두 가격 오류라고 부르지 않고 **거래 상태 동기화·분류 불일치 확인 대상**으로 남긴다. 상장 전 허수 6,093행과는 별도 지표이며 단순 합산하지 않는다. 0 가격만 검사하면 그럴듯한 양수 가격의 상장 전 허수를 놓칠 수 있다.

공식 거래일에 따른 기대 종목일 전수 대조, 역사 원가격·조정계수·기업행사·종목 식별자·비용 인수는 이번 수집 현황 조회만으로 통과 처리하지 않았다. corporate_event·DART 테이블의 존재도 정수주 기업행사 정산과 필요한 기간·원문 필드가 완성됐다는 증거는 아니다.

## 5. vectorbt에는 기간별로 다른 영향을 적용해야 한다

**2015~2023 정규장 연구에는 2026년 새 제도를 소급 적용하지 않는다.** 기존 가격 정의와 역사 제도·데이터 인수 기준을 유지하면 된다. 이번 제도 변경 자체 때문에 과거 전략 계산을 전면 재작성할 필요는 없다. 현재 실행 차단은 데이터 인수와 실제 정수주·기업행사·비용 모델 미검증 때문이다.

**9월 14일 이후 또는 복수시장·애프터마켓 전략은 현재 연구 runner로 재현할 수 없다.** `krx_lab`은 날짜/종목당 한 가격 행, 일봉 종가 신호→다음 거래일 시가 진입, 일봉 고저가 손절·익절 구조다. 통합 일봉의 저녁 고가로 오후 3시 이전 익절이 체결된 것처럼 계산하거나, 저녁에 확정된 거래량을 오후 3시 신호로 쓰면 시간상 사용할 수 없는 미래 정보를 사용한다.

- 거래소·세션·시간·당시 적격성, 신호 확정 시각, 다음 주문 가능 시각, VI·단일가·주문 종료·부분체결, 세션별 비용을 데이터 계약과 엔진에 함께 연결해야 한다.
- 현재 계약의 개장/폐장 필드는 있어도 실행은 일 단위다. 단일 시장·합성 프로필만 지원하고 REAL 입력을 `REAL_EXECUTION_NOT_ADMITTED`로 거절한다. 2024년 이후 잠금도 유지한다.
- vectorbt 라이브러리 본체는 분봉·사용자 주문 함수·배열 형태 비용/슬리피지를 다룰 기반이 있다. 한계는 라이브러리가 일봉 전용인 것이 아니라 **현재 연구 입력·실행 모델에 한국 복수시장 제도를 연결하지 않은 것**이다. 봉 빈도를 바꾸는 것만으로 해결되지 않는다.

## 6. 권장 우선순위와 현재 판정

**추천은 먼저 2015~2023 KRX 정규장 연구 경계를 고정하고 원천 인수부터 마무리하는 것이다.** 애프터마켓 전략은 별도 모델로 분리하면 기존 연구와 새 제도 대응이 섞이지 않는다.

1. ted-startup: signal 029 격리 변경의 검토·배포를 완료하고 6,093행 사본이 격리됐는지 검증한다. 거래량 0인데 `TRADED`인 역사 1,003행 및 KRX 4행의 근거 있는 상태 분류를 점검한다.
2. ted-startup: ka10081/ka10080의 거래소·세션 집계와 봉 타임스탬프 정의, 원문·실행·data revision을 고정한다. 최신 분봉 D-1 지연을 유지할지 당일 최종봉이 필요한지 목적에 따라 결정한다. 공식 기대 종목일·NXT 적격성으로 누락을 검사한다.
3. vectorbt: 인수된 형식의 읽기 전용 어댑터와 역사 원가격·기업행사·현실 비용을 검증하고, 그 뒤 실제 2015~2023 비교 실행을 지원한다.
4. 새 제도 전략이 필요하면 별도 범위로 세션 엔진을 구현·검증한다. 기존 holdout·전략 고정 조건 충족 전에는 2024년 이후 성과를 사용하지 않는다.

현재 판정: **운영 수집 지속 확인 / 최근 KRX 애프터마켓 분봉 저장 확인 / 전체 수집 완전성 미검증 / signal 품질 인수 미완료 / vectorbt 정식 실자료 실행 차단 유지.** 이번 검토의 완료와 전체 백테스트 프로젝트 완료는 구분한다.
