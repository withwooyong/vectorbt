# 백필 재점검과 HTS 대조 준비

2026-09-12 16:55~16:57 KST에 홈서버 KRX 일봉을 읽기 전용으로 재점검했다. **2015년 시작 구간 확장은 확인했지만, 인수 PASS는 아니다.** 종목 `102950`의 종가 0인 1,201행이 발견되어 현재 테이블을 그대로 투입하는 수익률 실행은 `BLOCKED`다. E0 진단과 E1 대조 설계는 계속할 수 있다. 백필 작업 자체의 완료 여부와 가격 조정 정의는 납품 기록이 없어 미확정이다.

먼저 아래 변화와 품질 문제를 확인하고, 가격 정의에 필요한 자료를 확보한 뒤 HTS 단일 조건을 대조한다. 기존 9월 10일 보고서는 당시 증거로 보존한다.

## 시작 구간은 확장됐으나 완전성을 뜻하지 않는다

행 수는 3,720,658행 증가했다. 현재 1,797종목이 2015-01-02부터 2,870행을 보유한다. 현재 상장일이 목표일보다 이른데 가격 시작이 늦은 종목은 거래소 5·리츠 1·코스닥 8개다. 이 수치는 상장일 정의와 역사 이력을 확인할 대상이며 누락 확정 건수가 아니다. 외부 달력과 당시 종목 집합이 없어 전체 백필 완료율을 계산하지 않는다.

## 종가 0 문제를 먼저 설명해야 한다

비양수 가격 1,201행은 모두 `102950`, 2015-01-02~2019-11-29에 집중된다. 모두 종가가 0이고 음수 가격은 없다. 이 중 거래량 0은 506행이므로 나머지 695행을 단순 무거래로 간주할 수 없다. 거래정지·조정 반올림·원천 오류 중 어느 원인인지 이번 집계만으로 판단하지 않는다.

백필 담당자에게 해당 구간의 원천 응답, 가격 변환 규칙, 거래 상태와 분석용 제외 사유를 요청한다. 원본을 임의 보정하거나 종가 0을 전일 종가로 채우지 않는다. 유효 분석 행 분리와 가격 의미가 확인되기 전에는 현재 테이블 전체의 E2/E3 실행을 차단한다. OHLC null·관계 위반, 음수 거래량·거래대금은 0건이지만 이 통과 항목이 종가 0 문제를 해소하지는 않는다.

## 가격 조정은 설정값만 확인됐으며 경제적 의미는 미확정이다

DB는 여전히 `adjusted=true`만 보유하며 현재 `stock_price_krx` 스키마에는 원가격·조정계수·행별 공급자 필드가 없다. 조회한 테이블 목록에서 manifest·revision 전용 테이블도 확인되지 않았다. 파일 형태의 납품 기록 존재 여부는 별도 확인이 필요하다.

로컬 `ted-startup`의 커밋 `278dd74d87eccefd6dc8e18606653ac07fb7bef2`에서 다음 경로를 읽었다. 해당 파일의 로컬 수정은 없지만, 서버 배포본과의 일치 및 이번 적재 경로는 검증하지 않았다.

- `src/backend_kiwoom/app/adapter/out/kiwoom/chart.py`: 수정주가 요청은 `upd_stkpc_tp="1"`로 전달한다.
- `src/backend_kiwoom/app/adapter/out/krx/client.py`: 별도 KRX 경로는 `get_market_ohlcv_by_date(..., adjusted=True)`를 호출한다.
- `src/backend_kiwoom/app/adapter/out/krx/mapper.py`: 이 경로의 매퍼는 종가 0 이하를 건너뛴다. 이것만으로 현재 DB의 적재 출처를 역추론할 수 없다.

다음 자료가 필요하다: 실제 백필 실행 ID·완료 로그·소스와 버전·범위·해시, 공급자별 분할/배당/권리락 반영과 반올림·소급 정책, 거래량·거래대금 단위, 기업행사 전후 원가격→조정가격 대조 표본. 요청 플래그만으로 배당 포함 총수익률 여부나 HTS 수정주가와의 동일성을 확정하지 않는다.

## HTS는 단일 조건부터 대조한다

권장 순서는 전일 거래량 → 가격/이평 → 최고종가다. 설정과 값의 의미를 하나씩 확정하기 위한 순서이며 아직 검색 결과를 확보하지 않았다. 상세 후보는 [조건 대응표](condition-map.md)를 따른다.

| 대조 대상 | 계산 제안 | 반드시 기록할 경계 |
| --- | --- | --- |
| 전일 거래량 | `volume[t-1] >= 100000` | 주/천주 등 단위, 정확히 임계값인 종목, 정지일 처리 |
| 가격/이평 | `close[t] > SMA60[t]` | 단순이평, 현재 봉 포함, 등호, 60봉 미만 처리 |
| 최고종가 | `close[t] > max(close[t-20:t-1])` | 현재 봉 제외 여부, 동률, 20봉의 시작·끝 |

대조 묶음에는 조건명과 UI 설정, KRX·수정주가 선택, 기준일·검색 시각, 시장·상품·제외 필터, 대상 종목 전체 목록과 검색 결과 코드를 남긴다. 양쪽에 필요한 일봉이 있는 완료 거래일을 공통 기준으로 정한다. DB 최신일은 9월 10일이므로 HTS가 다른 날짜를 평가하면 그대로 비교하지 않는다. `005930`, `000660`, `069500`은 값 확인 표본으로 사용하고 ETF 포함 여부는 대상 설정에 명시한다. 경계 사례가 없으면 경계 일치는 미검증으로 남긴다.

두 결과의 공통 포함·HTS만 포함·계산만 포함을 비교하고, 차이를 가격·창·등호·대상 범위별로 설명한 뒤에만 E1 일치로 표시한다. 이번 작업은 HTS 접근, 조건식 저장, 전략 구현 및 성과 계산을 수행하지 않았다.
