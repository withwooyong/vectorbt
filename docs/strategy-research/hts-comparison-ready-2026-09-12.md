# HTS 단일 조건 대조 준비

이 문서는 HTS 결과를 받을 때 곧바로 값과 포함 여부를 비교하기 위한 실행안이다. **2026-09-10 KRX 마감 기준 3종목의 DB 계산·독립 검산을 준비했으며, HTS 결과 일치는 아직 미검증이다.** 가격 정의는 [원인 추적 보고서](price-provenance-review-2026-09-12.md)의 한계가 적용된다. 아래 값은 연구 계산안이며 매매 신호나 성과가 아니다.

## 먼저 같은 날짜·대상·가격 설정을 고정한다

첫 대조 대상은 `005930` 삼성전자, `000660` SK하이닉스, `069500` KODEX 200이다. ETF 1개를 포함한 값 확인 표본이며 전체 코스피 대상이 아니다. HTS가 이 3개를 대상으로 검색할 수 없으면 전체 대상과 결과를 보관하고 이 표본의 포함 여부만 먼저 비교한다.

기준일은 **2026-09-10**, 이전 관측일은 **2026-09-09**다. HTS가 이 완료 거래일을 평가할 수 있는지 먼저 확인한다. 불가능하면 양쪽에 가격이 확보된 다른 완료일로 바꾸고 SQL 07·08을 함께 수정·재실행한다. 다른 날짜의 결과를 현재 표와 비교하지 않는다.

## 전일 거래량부터 하나씩 대조한다

1. **전일거래량:** 제안 `volume[t-1] >= 100000`. HTS의 주/천주 등 단위를 확인한 뒤 이에 해당하는 임계값을 입력한다.
2. **가격-이동평균 비교:** 제안 `close[t] > SMA60[t]`. 종가, 단순이평, 현재 봉 포함 60개, 엄격한 초과 조건으로 대응 가능한지 확인한다.
3. **최고종가:** 제안 `close[t] > max(close[t-20], ..., close[t-1])`. 현재 봉 제외와 동률 미포함을 확인하며 UI가 다른 의미라면 정의 불일치로 기록한다.

세 조건은 단독으로 검사한다. 상세 조건명과 공식 조사 범위는 [조건 대응표](condition-map.md)를 따른다. 주식 수·기간 봉 수·부등호를 임의로 맞추어 결과 일치를 만들지 않는다.

## DB 기준값은 3종목 모두 거래량 조건만 충족한다

아래 SMA는 표시용 소수 6자리다. 판정에는 반올림 전 값 대신 정확한 정수 비교 `close*60 > sum(60 closes)`를 사용했다. 60봉 미만·0 이하 종가·NULL이 있는 창은 판정하지 않는다. 가격이 나쁜 봉을 먼저 삭제해 창 길이를 바꾸지 않는다.

| 종목 | 종가 | 전일 거래량 | SMA60 | 이전 20봉 최고종가 | 거래량 / 이평 / 최고종가 |
| --- | ---: | ---: | ---: | ---: | --- |
| 000660 | 1,853,000 | 3,526,484 | 1,924,566.666667 | 1,856,000 | 참 / 거짓 / 거짓 |
| 005930 | 269,000 | 16,370,962 | 274,166.666667 | 281,500 | 참 / 거짓 / 거짓 |
| 069500 | 111,865 | 24,388,329 | 113,926.566667 | 112,100 | 참 / 거짓 / 거짓 |

이 표본에는 임계값 동률, 거래량 조건 실패, 이평·최고종가 조건 성공 사례가 없다. 따라서 모두 맞더라도 전체 조건 동작·등호 처리 검증은 완료되지 않는다. 다음 확장 표본은 각 조건의 성공/실패, 임계값과 정확한 동률, 짧은 이력과 거래정지 사례를 포함하도록 고른다.

## HTS 결과 수령 시 채울 기록

| 필드 | 현재 값 또는 상태 |
| --- | --- |
| 기준일 / DB 가격 기준 | 2026-09-10 / KRX adjusted=true |
| HTS 버전·검색 시각·실제 평가일 | 미확보 |
| 조건명·세부 UI·단위·봉전·등호 | 위 제안과 실설정 대조 필요 |
| HTS KRX·수정주가·배당락/권리락 설정 | 미확보; UI에서 제공되는 항목만 기록 |
| 전체 대상 코드 / 시장·상품·제외 필터 | HTS 결과와 함께 확보 |
| 조건별 전체 결과 코드 | 미확보; 6자리 코드와 앞자리 0 보존 |
| 공통 포함 / HTS만 포함 / 계산만 포함 | 결과 수령 후 집합 비교 |
| 차이 사유 | 가격·단위·창·등호·대상 범위별 분류 |
| 최종 상태 | `PREPARED_NOT_VALIDATED` |

설정과 대상이 같고 양쪽 결과 차이를 설명한 뒤 해당 표본 범위에서만 일치로 표시한다. 실제 검색 결과가 없으므로 조건식을 저장하거나 일치 완료로 승격하지 않았다.
