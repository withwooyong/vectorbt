# KRX 일봉 전략과 영웅문4 조건검색 대응표

이 문서는 KRX 일봉 백테스트의 추세, 최고종가, 단기 되돌림, 거래량 조건을 영웅문4 [0150]에 대응시킨 초안이다. 조건명은 공식 도움말에서 확인한 범위이고, 계산식·임계값은 우리 연구 제안이다. HTS 저장·검색 결과와 Python의 일치 검증은 아직 하지 않았다.

## 공통 기준

- `[일]`, `KRX`, 수정주가, 일봉 완성 시점 `t` 신호와 `t+1` 체결을 기본으로 한다. 장중 `0봉전`은 미완성 봉일 수 있다.
- `0봉전`은 현재 봉, `1봉전`은 직전 봉이다. `20봉`, `5일`, 임계값은 예시 파라미터이며 등호 처리와 허용 기간 범위는 미확정이다.

## 대응표

| 전략 요소 | 공식 조건명과 UI 설정안 | 우리 계산 제안 | 미확정 경계 |
| --- | --- | --- | --- |
| 추세: 골든크로스 | `기술적분석 > 주가이동평균 > 주가이동평균돌파`; `[일] 0봉전 종가 / 5 이평 종가 / 20 이평 / 골든크로스` | `SMA5_t>SMA20_t` 및 `SMA5_{t-1}<SMA20_{t-1}` | 현재 봉 마감 전 평가와 등호 처리. 단순이평 기간 범위는 HTS 확인 필요 |
| 추세: 정배열 | `기술적분석 > 주가이동평균 > 주가이동평균배열(3개)`; `[일] 0봉전 5>10>20` | `SMA5_t>SMA10_t>SMA20_t` | 상태 조건이므로 새 교차 시점과 다르다 |
| 최고종가 돌파 | 공식 항목명 `최고종가`의 세부 UI와 기준 창은 확인 필요 | 기본안 `close_t>max(close_{t-20:t-1})` | `신고가`와 혼용하지 않는다. 영웅문4에서 `최고종가`의 기간·현재 봉 포함·등호·돌파 방향을 확인하기 전에는 HTS 대응을 확정하지 않는다 |
| 단기 되돌림: 주가등락률 | `시세분석 > 가격조건 > 주가등락률`; 설정안 `[일] 3봉전 종가 대비 0봉전 종가 -3% 이하` | `100*(close_t/close_{t-3}-1)<=-3` | 정확한 봉전·등호·허용값을 확인. 중기 추세 필터는 아래 가격/이평 비교와 AND |
| 가격/이평 상태 | 공식 `가격-이동평균 비교` 항목의 종가와 60기간 단순이평 비교 설정안 | `close_t>SMA60_t` | 정확한 가격 선택·기간·경계 UI 확인 전. `주가이동평균비교`의 1이평/60이평 대안도 동일성 확인 전에는 사용하지 않음 |
| 거래량: 절대 평균량 | `시세분석 > 거래량/거래대금 > 평균거래량`; 기간 및 현재 봉 포함/제외 설정 | `mean(volume_{t-20:t-1})>=threshold` | 평균 기간 범위, 현재 봉 포함 기본값, 장중 0봉전 처리 |
| 전일 거래량 | `전일거래량` 설정안: 100,000 이상 | `volume_{t-1}>=100000` | [실험 명세](experiment-spec.md)의 공통 필터. 단위 및 설정값 대조 필요 |
| 거래량: 상대비율 1차 | `시세분석 > 거래량/거래대금 > 거래량비율`; `[일] 1봉전 거래량 대비 0봉전 거래량 비율 150% 이상` | `volume_t/volume_{t-1}>=1.5` | 전봉 대비 조건은 확인된 예시로 우선 사용한다 |
| 거래량: 기간 평균 대비 | `기간내 평균거래량비율` 항목은 공식 목록에 있으나 세부 UI 확인 전 보류 | 보류. 확정 전에는 전봉 대비 `거래량비율`로 대체 | 기간 창·기준봉 포함/제외·현재 봉 포함 여부를 HTS에서 확인해야 한다 |

## 전략군별 독립 조합 3개

전략 요소 전체를 한 식에 AND로 묶지 않고, 아래 세 후보를 서로 독립적으로 비교한다.

1. **추세군**: `주가이동평균돌파` 5·20 골든크로스. 정배열 5>10>20은 별도 변형으로 비교한다.
2. **최고종가군**: 공식 `최고종가` 세부 UI가 확인된 뒤, 이전 20봉 최고종가 돌파 정의와 단독 비교한다.
3. **되돌림군**: `주가등락률` 하락 구간과 가격/이평 상태 조건을 조합한다. 세부 후보 수·공통 거래량 필터는 [실험 명세](experiment-spec.md)가 기준이며, 이 표의 추가 거래량 변형은 1차 실험에 넣지 않는다.

## 순위 조건을 백테스트 순위로 대체하지 않기

`순위분석 > 평균거래량 순위`는 공식 설명상 금일 포함 5일간 평균거래량의 상·하위 검색이다. 최근 6개월 평균거래량 상위 20개나 6개월 수익률 표준편차 순위와 동일하지 않다. 후자는 유니버스·기준일을 고정해 Python에서 별도 계산한다. HTS 순위 사용 시 조건명, 기간, 대상 시장, 제외 종목, 검색 시각을 기록한다.

## 공식 근거와 설계안

공식 [0150 조건검색 도움말](https://download.kiwoom.com/hero4_help_new/0150.htm)은 KRX 시세 선택, `0봉전` 기준, 조건 조합과 저장을 설명한다. 공식 [개별조건 PDF](https://download.kiwoom.com/hero4_help_doc/KiwoomHero4_AdvancedSearch.pdf)는 p3에서 단순이평을 설명하고, p4에서 상향 돌파(`1봉전 A<B`, `0봉전 A>B`)와 정배열을 정의하며, p6-7의 주가등락률·가격조건, p10의 평균거래량·거래량비율, 인쇄 p69-70의 이동평균 교차·배열 예시를 제공한다. PDF에 없는 `최고종가` 세부 UI는 확인 전이다.

위 부등식의 Python 표현, 현재 봉을 제외한 이전 20봉 최고종가 창, `t` 종가 후 `t+1` 체결, 임계값은 연구 설계안이다. 공식 문서가 이 계산 규칙과 결과 일치를 보증하는 것은 아니다.

## 검증 게이트

HTS live 검증은 미실시다. 다음 단계에서 동일한 KRX·수정주가·기준일로 각 조건을 단독 검색하고, 최고종가 기준 창, 평균량 포함 여부, 경계값, `0봉전` 마감 상태를 표본 종목으로 대조한 뒤에만 “HTS 일치”로 승격한다.
