# 실행 안내 문서의 검증 범위

이 기록은 국내주식 백테스트·자동매매 안내에서 **실제로 확인한 것과 아직 실행하지 않은 것을 구분**한다. 문서, 합성 데이터 예제 및 회귀 검사는 실제 종목 수익성이나 주문 가능성을 입증하지 않는다. 초기의 PostgreSQL 접속 시간 초과는 전원 가동 후 해소됐다. 후속 실시간 집계·단일종목 추출은 성공했으며 가격 인수와 실제 수익성 검증은 미완료다.

## 확인한 환경과 데이터 증거

| 항목 | 확인 결과 |
| --- | --- |
| 작업 기준 HEAD | `4bb110d` — 가격 원인 추적과 HTS 표본 대조 준비 및 독립 검산 |
| 최초 문서 작업 시작 Git 상태 | clean; 후속 갱신은 이전 문서·예제와 사용자 prompt/ 미추적 파일을 보존 |
| 기존 가상환경 | Python 3.14.6, vectorbt 1.1.0, Plotly 6.9.0 import 성공 |
| 주요 설치 버전 | NumPy 2.5.3, pandas 3.0.5, Numba 0.67.0 |
| 과거 증거 검산 | `verify_evidence.py` PASS: 과거 연도 합계·시장 분해·API/DB 7일·API 경계 |
| 후속 증거 검산 | `verify_followup_evidence.py` PASS: 과거 0원 봉 집계·180봉·3개 조건 SQL/Python 검산 |
| 홈서버 접속 | 초기 시간 초과 → 13:07 KST 접속 복구, 후속 14:12 KST 읽기 전용 조회 성공 |
| 현재 입력 범위 | adjusted=true 8,789,127행·5,011종목, 2015-01-02~2026-09-10 |

과거 증거 PASS를 현재 DB PASS로 해석하지 않는다. 후속 실측에서 종가 0인 1,201행, 비양수 OHLC 89,239행을 확인했다. 가격 조정 계보·정지 상태의 의미를 확정한 것은 아니다.

## 문서·예제 검증

PowerShell 코드 블록은 PowerShell 파서로 문법을 검사한다. 후속 작업에서 SQL 05(진단), 10(현재 집계), 09(단일종목 추출)를 실제 PostgreSQL에서 읽기 전용으로 실행했다. 09는 삼성전자 2,870행을 반환했지만 실제 데이터 수익률은 계산하지 않았다. 모든 과거 SQL을 재실행한 것은 아니다.

| 검사 | 결과 |
| --- | --- |
| 예제 회귀 검사 | `python -m pytest docs/strategy-research/test_research_backtest.py -q` → **11 passed**, 18.64초 |
| 합성 데이터 CLI | `--demo --strategy all --cost-bps 30` → 6개 후보·출력 4종 생성 성공 |
| CSV 경로 CLI | 합성 데이터를 CSV로 저장 후 `--input … --price-semantics-reviewed --strategy all --cost-bps 50 --delay 2 --start 2024-04-01 --end 2024-06-28` → 6개 후보·출력 4종 생성 성공 |
| 계산 대조 | vectorbt Numba 포트폴리오와 독립 원장의 자산 및 체결 index·방향·수량·가격·비용을 `rtol=1e-10`, `atol=1e-12`로 대조 |
| 주요 회귀 내용 | 6개 후보의 독립 pandas 신호, 다음 봉/추가 지연 체결, 10봉 청산, 미래 데이터 추가 시 기존 결과 불변, 초기 가치 포함 낙폭, 기간 경계, 잘못된 가격 입력 거절 |
| 문법 | 예제 Python 컴파일 통과, 메인 안내의 PowerShell 블록 11개 파싱 통과 |
| 문서 정합성 | Markdown 5개 UTF-8·코드 블록·공백 검사, 상대 링크 35개, 증거 JSON 2개 파싱 통과; `git diff --check` 통과 |

CSV 경로 검사도 **합성 데이터**이며 국내주식 DB 성과를 실행한 것이 아니다. CLI 결과 폴더와 실행 코드 해시는 [실행 증거](evidence/guide-cli-validation-2026-09-13.json)에 저장했다. GitHub 비교의 10개 저장소 커밋·릴리스·라이선스 확인값은 [공개 저장소 스냅샷](evidence/open-source-snapshot-2026-09-13.json)에 남겼다.

## 후속 요구와 현재 DB 검증

사용자의 최대 약 20종목·실시간 조건검색·AI 매수 검토·체결 후 목표가 매도·분석 재활용·월평균 1,000만 원 목표를 반영했다. [구조·자금 계획](capital-and-system-design.md), [조건검색 연동](broker-condition-integration.md), [갱신한 AI 로드맵](paper-live-news-roadmap.md)을 연결했다. 기존 Python 예제는 변경하지 않아 11개 회귀 검사는 이전 실행 기록이며 이번 문서 갱신에서 반복하지 않았다.

- [DB 현재 집계](evidence/db-current-status-2026-09-13.json), [0원 진단](evidence/db-reconnected-2026-09-13.txt): 연결·조회 성공 및 현재 가격 이상을 구분.
- [DB 추출 증거](evidence/db-export-verified-2026-09-13.json): SQL 09 실행, 데이터 경로·해시·범위·행 수. 성과 계산 없음.
- [투자금 계산](evidence/capital-scenarios-2026-09-13.json): 가정 수익률별 필요자본·복리 환산·낙폭·운영비를 코드로 재계산. 실측 기대수익 아님.
- 사용자 프롬프트 원본 4개는 변경하지 않고, 읽은 내용을 바탕으로 최적화된 템플릿을 문서에만 추가.
- 도식은 Markdown Mermaid 3개이며 일반 텍스트 설명을 함께 제공. 별도 이미지 렌더링은 미실시. 브로커 API는 공식 문서만 확인했고 계정 호출은 하지 않음.
- 후속 검사: Markdown 7개 UTF-8·코드 블록·공백, 상대 링크 68개, PowerShell 명령 11개 파싱 통과. 자본 표를 코드로 독립 검산했고 기존 실행 예제 SHA-256이 이전 검증 기록과 같음을 확인했다.
- 프롬프트 4개의 파일명·크기·SHA-256은 `evidence/prompt-source-manifest-2026-09-13.json`에 보존했다.

## 팀 작업과 비용 관리 방식

사용자의 팀 구성 요청에 따라 본 에이전트가 저장소 확인·실행 안내·통합 검토를 담당하고, 세 개의 독립 범위만 위임했다. 각 작업에는 필요한 파일과 요구만 전달했고 저장소 전체·원자료 전체를 복제하지 않았다.

| 역할 | 선택한 모델 | 범위 |
| --- | --- | --- |
| 공개 GitHub 조사 | `gpt-5.6-sol`, medium | 공식 README·라이선스·개발 현황과 대안 비교 |
| 모의·실전 설계 | `gpt-5.6-terra`, medium | 뉴스 시점·가격 정책·주문 복구·전환 기준 |
| 실행 예제 | `gpt-5.6-terra`, high | 작은 연구용 CLI·독립 장부 대조·회귀 검사 |

모델 이름은 이 세션에서 지정한 내장 에이전트 설정이다. 실제 과금액·정확한 사용 토큰 계측은 제공되지 않아 절감 금액을 주장하지 않는다. Orca 연동은 앱 상태 확인에 성공했지만 Run 생성이 `no_active_sender_terminal`로 실패하여 작업자를 만들지 않았고, 내장 에이전트로 팀 작업을 수행했다.

## 미실행 및 변경 경계

- 실제 국내주식 성과 산출, HTS 대조, 본 명세의 역사 유니버스·공동 계좌·기업행사 검증.
- 모의·실전 계좌 연결, 뉴스 공급 계약·실시간 수집, 증권사 API 주문·취소·잔고 조회.
- 다른 오픈소스의 로컬 설치·성능 측정·어댑터 실행. 공식 자료 비교는 [비교 문서](open-source-comparison-2026-09-13.md)를 따른다.
- Rust 경로 실행·빌드, 저장소 전체 pytest, MkDocs 빌드. 제품 라이브러리와 사이트의 `docs/docs/`를 수정하지 않아 해당 범위를 실행하지 않았다.
- 커밋·푸시·PR·배포·원격 CI 실행. 이번 요청은 문서 전달이며 이 작업에서 수행하지 않았다.

추가한 코드는 문서 명령의 동작을 확인하는 연구 예제와 검사뿐이다. 원본 DB, 수집 코드, vectorbt 제품 코드, 의존성 설정을 변경하지 않았다.
